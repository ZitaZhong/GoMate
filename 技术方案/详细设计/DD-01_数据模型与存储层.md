# DD-01 数据模型与存储层 · 详细设计

**详细设计系列 · 地基契约文档 · v1.0 · 2026 年 7 月**

> 本文是「周末去哪儿」详细设计系列的**地基**：定义全系统共享的**数据模型、枚举、JSONB 规范、存储选型、键空间与生命周期**。其它所有模块（DD-02 ~ DD-14）的表结构与字段一律**以本文为准**，不得各自另立。
>
> **上游依据**：`周末去哪儿_技术架构与实现方案_v1.md`（§6 数据模型、§3.4 存储）、`周末去哪儿_技术架构_v1.1增补.md`（增补 A 检索、增补 C 记忆）、两份 PRD。
> **下游消费者**：全部模块。
> **本文约定**：所有 DDL 为 PostgreSQL 16+ 方言；时间统一 `TIMESTAMPTZ`（UTC 存储，展示层转 `Asia/Shanghai`）；金额单位分（`INT`）避免浮点。

---

## 1. 模块职责与边界

| 项 | 说明 |
|---|---|
| **职责** | 提供单一事实来源（single source of truth）的持久化层：关系数据、地理数据、向量数据、缓存、对象存储、编排检查点。 |
| **边界内** | 表结构、索引、枚举、JSONB schema、迁移、种子数据、保留/TTL、数据归属矩阵。 |
| **边界外** | 业务逻辑（在各领域模块）、检索算法（DD-05）、编排状态流转（DD-02）——本文只定义它们**落库的形态**。 |
| **架构位置** | v1 §4.1 分层图最底层"数据存储层"。 |

**设计原则**：① 一个 Postgres 打三份工（关系 + PostGIS + pgvector），契合"轻后端"；② 证据是一等公民（每个对外事实字段带 `evidence`）；③ 隐私最小化（精确 PII 不落库或脱敏落库）；④ 读写解耦（活动库由情报流水线异步预热，规划时只读）。

## 2. 存储选型与扩展清单

```text
PostgreSQL 16+              主库：关系 + 事务 + JSONB
  ├─ PostGIS 3.4+           地理：GEOGRAPHY(Point,4326)、ST_DWithin 按米过滤
  ├─ pgvector 0.8+         向量：vector 类型 + HNSW（去重/语义检索）
  ├─ pgvectorscale         规模到千万级切 StreamingDiskANN + SBQ（触发条件见 §11）
  └─ (可选) pg_search/zhparser  BM25 / 中文分词（增补 A）
Redis 7+                   缓存 / 令牌桶限流 / 配额计数 / Celery broker / 分布式锁
对象存储 OSS/S3            回填截图（短生命周期）、大文件
LangGraph PostgresSaver    编排检查点（自建表，§9）—— 与主库同实例、独立 schema
```

**扩展安装**（迁移首步）：
```sql
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS vectorscale CASCADE;   -- 自动带 pgvector
-- 可选：CREATE EXTENSION IF NOT EXISTS pg_search;   -- BM25（否则用内建 tsvector）
```

## 5. 证据（Evidence）的落库规范 —— 全系统一等公民

证据**不单独建强关系表**，而是作为**标准化 JSONB 内嵌**在每个"对外事实"旁（与 v1 `Fact/Evidence` 一致，读写零 JOIN、随字段走）。规范如下：

```jsonc
// evidence JSONB 标准结构（DD-03 的 Provenance Guard 读写此结构）
{
  "source_type": "official_venue",          // 见 source_type 枚举
  "source_url":  "https://...",             // 可空
  "fetched_at":  "2026-07-18T10:00:00Z",    // 可空
  "verification_status": "official_source_confirmed",  // 六态之一
  "confidence":  0.92,                       // 0~1
  "note":        "解析自官方展览页"           // 可空
}
```

**校验**：应用层用 Pydantic `Evidence` 模型（DD-03 §定义）校验后写入；DB 侧用 `CHECK (jsonb_typeof(evidence)='object')` 兜底。**审计可选表** `evidence_audit(id, entity_table, entity_id, field, evidence jsonb, created_at)` —— 仅当需要合规溯源时开启，默认不启用（省成本）。

## 6. 核心表 DDL —— 用户与计划域

```sql
-- 6.1 用户（隐私优先：默认匿名，不存手机号/真实姓名于主表）
CREATE TABLE users (
  id           BIGSERIAL PRIMARY KEY,
  anon_id      TEXT UNIQUE NOT NULL,           -- 客户端匿名标识（无 PII）
  created_at   TIMESTAMPTZ DEFAULT now(),
  last_seen_at TIMESTAMPTZ
);

-- 6.2 用户长期上下文（v1 §8.3；v1.1 增补 C：v0.1 仅此表，v0.2 再上 Mem0）
CREATE TABLE user_context (
  user_id      BIGINT PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  home_cities  JSONB DEFAULT '[]',             -- ["上海"] 常用出发地
  budget_band  JSONB,                          -- {"min":1500,"max":3000} 单位元
  prefer_flight BOOLEAN,
  accept_night_train BOOLEAN,
  interests    JSONB DEFAULT '[]',             -- ["展览","演出"]
  dietary      JSONB DEFAULT '[]',             -- ["清真","不吃辣"]
  visited      JSONB DEFAULT '[]',             -- 去过的城市/活动（减少重复推荐）
  updated_at   TIMESTAMPTZ DEFAULT now()
);
-- 隐私：以上均为用户显式授权后保存；可一键导出/删除（§12）。

-- 6.3 计划（一次周末规划 = 一条 plan；thread_id 关联 LangGraph 检查点）
CREATE TABLE plans (
  id           BIGSERIAL PRIMARY KEY,
  organizer_user_id BIGINT REFERENCES users(id),
  stage        plan_stage NOT NULL DEFAULT 'explore',
  thread_id    TEXT UNIQUE NOT NULL,           -- = 'plan:{id}'，DD-02 checkpoint 线
  constraints  JSONB NOT NULL DEFAULT '{}',    -- 聚合后的匿名约束（schema 见 §8.1）
  weekend_start TIMESTAMPTZ,                    -- 目标周末起（本地周五）
  weekend_end   TIMESTAMPTZ,
  created_at   TIMESTAMPTZ DEFAULT now(),
  updated_at   TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX ON plans (organizer_user_id, created_at DESC);

-- 6.4 同行人（匿名邀请；v0.2 多人协作，v0.1 仅组织者一条）
CREATE TABLE plan_members (
  id           BIGSERIAL PRIMARY KEY,
  plan_id      BIGINT NOT NULL REFERENCES plans(id) ON DELETE CASCADE,
  invite_token TEXT UNIQUE,                    -- 匿名邀请链接令牌（最小权限、可过期）
  anon_label   TEXT,                           -- "同伴A"（不暴露身份）
  is_organizer BOOLEAN DEFAULT FALSE,
  joined_at    TIMESTAMPTZ
);

-- 6.5 同行人约束（脱敏粒度：商圈级而非门牌；个人预算不外显）
CREATE TABLE party_constraints (
  id           BIGSERIAL PRIMARY KEY,
  plan_id      BIGINT NOT NULL REFERENCES plans(id) ON DELETE CASCADE,
  member_id    BIGINT REFERENCES plan_members(id) ON DELETE CASCADE,
  origin_area  TEXT,                           -- "上海·徐汇"（商圈级，脱敏）
  origin_geo   GEOGRAPHY(Point,4326),          -- 商圈中心坐标（非家庭门牌）
  earliest_depart TIMESTAMPTZ,
  latest_return   TIMESTAMPTZ,
  budget_band  JSONB,                          -- 个体预算：仅参与聚合，默认不外显
  prefer_flight BOOLEAN,
  accept_night_train BOOLEAN,
  prefs        JSONB DEFAULT '[]',
  dietary      JSONB DEFAULT '[]',
  created_at   TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX ON party_constraints (plan_id);
```

## 7. 核心表 DDL —— 城市与活动域（DD-06 / DD-08 写，DD-05 检索）

```sql
-- 7.1 城市档案（人工/运营维护，v0.1 先做 15~20 城）
CREATE TABLE city_playbook (
  id            BIGSERIAL PRIMARY KEY,
  city_code     TEXT UNIQUE NOT NULL,          -- 高德 adcode
  name          TEXT NOT NULL,
  center        GEOGRAPHY(Point,4326),         -- 城市中心（探索期粗估用）
  stations      JSONB,   -- [{name,type:'rail'|'air',location:{lng,lat},access_note}]
  lodging_areas JSONB,   -- [{name,center,dining_density,night_transit_risk,eta_notes}]
  hubs          JSONB,   -- 核心商圈/文化区
  transit_notes JSONB,   -- 公共交通特点/夜间风险
  weekend_tags  TEXT[],  -- 周末适配标签
  seasonal_risk JSONB,
  updated_at    TIMESTAMPTZ DEFAULT now()
);

-- 7.2 场馆/主办方目录（活动的空间锚点）
CREATE TABLE venues (
  id           BIGSERIAL PRIMARY KEY,
  city_code    TEXT REFERENCES city_playbook(city_code),
  name         TEXT NOT NULL,
  location     GEOGRAPHY(Point,4326),
  category     TEXT,                            -- 博物馆/剧院/体育馆/展馆
  official_url TEXT,
  UNIQUE (city_code, name)
);
CREATE INDEX ON venues USING GIST (location);

-- 7.3 来源注册表（DD-06 情报流水线；v1 §8.2）
CREATE TABLE source_registry (
  id             BIGSERIAL PRIMARY KEY,
  name           TEXT NOT NULL,
  city_code      TEXT,
  source_type    source_type NOT NULL,
  entry_url      TEXT NOT NULL,
  parser_kind    TEXT,                          -- static/js/rss/api
  fetch_interval INTERVAL DEFAULT '1 day',      -- 低频克制
  robots_ok      BOOLEAN DEFAULT TRUE,
  trust_level    INT DEFAULT 3,                 -- 1~7 对应可信度分级
  enabled        BOOLEAN DEFAULT TRUE,
  last_fetched_at TIMESTAMPTZ
);

-- 7.4 抓取原始页（供抽取与回溯；DD-06）
CREATE TABLE raw_pages (
  id           BIGSERIAL PRIMARY KEY,
  source_id    BIGINT REFERENCES source_registry(id) ON DELETE CASCADE,
  url          TEXT NOT NULL,
  http_status  INT,
  content_hash TEXT,                            -- 去重：无变化不重抽
  etag         TEXT,
  clean_md     TEXT,                            -- Readability/Jina 清洗后的正文
  fetched_at   TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX ON raw_pages (source_id, fetched_at DESC);

-- 7.5 活动（核心资产：每条=带证据的结构化记录；v1 §6.3 + v1.1 增补 A）
CREATE TABLE activities (
  id            BIGSERIAL PRIMARY KEY,
  fingerprint   TEXT UNIQUE,                    -- 归一指纹（去重/实体对齐 一级）
  title         TEXT NOT NULL,
  city_code     TEXT REFERENCES city_playbook(city_code),
  venue_id      BIGINT REFERENCES venues(id),
  venue         TEXT,                           -- 冗余场馆名（抽取原文）
  location      GEOGRAPHY(Point,4326),
  start_at      TIMESTAMPTZ,
  end_at        TIMESTAMPTZ,
  price_text    TEXT,                           -- 原文价格，不做换算臆测
  booking_url   TEXT,
  category      TEXT,                           -- 展览/演出/赛事/市集...
  evidence      JSONB NOT NULL,                 -- §5 标准结构
  verification_status verification_status NOT NULL,
  availability_status availability_status DEFAULT 'user_must_confirm',
  embedding     VECTOR(1024),                   -- BGE-M3；DD-05 检索
  embedding_version TEXT DEFAULT 'bge-m3-v1',   -- 换模型全量重嵌用
  search_tsv    TSVECTOR GENERATED ALWAYS AS (  -- BM25/全文（增补 A）
                  to_tsvector('simple', coalesce(title,'')||' '||coalesce(venue,''))) STORED,
  expires_at    TIMESTAMPTZ,                    -- 过期自动下架
  created_at    TIMESTAMPTZ DEFAULT now(),
  updated_at    TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX ON activities USING GIST (location);
CREATE INDEX ON activities (city_code, start_at);
CREATE INDEX ON activities USING GIN (search_tsv);
CREATE INDEX ON activities USING hnsw (embedding vector_cosine_ops);
CREATE INDEX ON activities (verification_status) WHERE verification_status
  IN ('official_source_confirmed','public_source_observed');

-- 7.6 活动人工审核队列（DD-06 情报流水线：抽取失败/冲突/低置信入队人工复核）
CREATE TABLE activity_review_queue (
  id           BIGSERIAL PRIMARY KEY,
  activity_id  BIGINT REFERENCES activities(id) ON DELETE CASCADE,  -- 可空（抽取失败时尚无活动）
  source_id    BIGINT REFERENCES source_registry(id),
  reason       TEXT NOT NULL,        -- extract_failed/conflict/low_confidence/quote_mismatch/geocode_failed
  payload      JSONB,                -- 待审内容/冲突详情
  status       TEXT DEFAULT 'pending',  -- pending/approved/rejected/fixed
  reviewer     TEXT,
  created_at   TIMESTAMPTZ DEFAULT now(),
  reviewed_at  TIMESTAMPTZ
);
CREATE INDEX ON activity_review_queue (status, created_at);
```

## 8. 核心表 DDL —— 回填与行程域（DD-10 / DD-11 / DD-12 / DD-13）

### 8.1 `plans.constraints` / `party.aggregate` JSONB 规范（约束的权威 schema）

```sql
-- 8.2 回填的交通/住宿（BYO Booking；确认后才生效；v1 §6.3 / DD-10）
CREATE TABLE bookings (

-- 8.3 餐饮候选（DD-11；动线上的饭点）
CREATE TABLE dining_picks (

  plan_id      BIGINT NOT NULL REFERENCES plans(id) ON DELETE CASCADE,

  name         TEXT NOT NULL,
  location     GEOGRAPHY(Point,4326),
  cuisine      TEXT, price_band JSONB, open_hours TEXT, phone TEXT,

  from_geo     GEOGRAPHY(Point,4326), to_geo GEOGRAPHY(Point,4326),
  mode         TEXT,                            -- walk/transit/drive/taxi

-- 8.5 时间线槽位（DD-12 求解产出）
CREATE TABLE timeline_slots (

  plan_id      BIGINT NOT NULL REFERENCES plans(id) ON DELETE CASCADE,

  start_at     TIMESTAMPTZ, end_at TIMESTAMPTZ,
  kind         slot_kind NOT NULL,
  ref_table    TEXT, ref_id BIGINT,             -- 指向 activities/bookings/dining/route_legs

CREATE TABLE reminders (

  payload      JSONB NOT NULL,
```

## 9. 基础设施：Redis 键空间 / 对象存储 / 编排检查点

### 9.1 Redis 键空间（缓存/限流/配额/锁/队列）

| 键模式 | 用途 | 值 / TTL |
|---|---|---|
| `cache:{provider}:{sha1(req)}` | 外部 API 响应缓存（DD-04） | JSON；分层 TTL：地理编码 30d、路线 7d、天气 1h、活动检索 10min、LLM 24h |
| `rl:{provider}` | 令牌桶限流（Lua 原子） | 令牌数 + 时间戳 |
| `quota:{provider}:{yyyymmdd}` | 日成本计数（接近上限降级） | 计数；当日过期 |
| `lock:plan:{id}` | 同一 plan 串行恢复（DD-02） | 短 TTL + 看门狗 |
| `invite:{token}` | 邀请令牌→plan_id 快速校验 | plan_id；可过期 |
| Celery broker/backend | 异步任务（抓取/抽取/提醒） | — |

### 9.2 对象存储（OSS/S3）布局与生命周期

```text
bucket: wheretogo-uploads
  screenshots/{plan_id}/{uuid}.jpg   回填截图；生命周期规则 7 天自动删除（隐私）
  ics/{plan_id}.ics                   动态日历（也可实时生成不落盘）
```

- 截图仅用于 OCR 抽取（DD-10），抽取完可更早删；默认 7 天兜底。
- 访问用**短时效签名 URL**，不公开可读。

### 9.3 LangGraph 检查点存储（DD-02 详述，本文仅定位）

- 用 `PostgresSaver`，独立 schema `langgraph`（表 checkpoints / checkpoint_writes / checkpoint_blobs 由库自建）。
- `thread_id = plans.thread_id = 'plan:{id}'`。
- TTL/归档：见 §12.3。

## 10. 迁移、种子数据与扩容

### 10.1 迁移（Alembic）

- 每次变更一个 revision；扩展安装为首个 revision；迁移幂等可重跑。
- 破坏性变更走“新增列→回填→切换→删旧列”四步，不停机。
- **embedding 换模型**：新 `embedding_version`，后台批量重嵌，双跑校验后切换（增补 A 铁律）。

### 10.2 种子数据（v0.1 必备）

- `city_playbook` 15~20 城（上海优先），含 stations/lodging_areas/hubs（运营录入，模板化）。
- `source_registry` 每城若干高价值官方源（博物馆/大剧院/美术馆/体育馆/文旅日历）。
- 种子以 YAML/CSV 维护，迁移时导入。**这是运营活，是护城河。**

### 10.3 扩容触发（来自《向量库调研》）

- 活动向量默认 HNSW（百万级舒适）。
- 单表活跃向量 > ~5000 万 / QPS 持续 > 数千 / 需分布式 → 先切 pgvectorscale StreamingDiskANN+SBQ（同库、内存可控），再评估外挂 Qdrant。

## 11. 数据保留、隐私与合规

### 11.1 隐私最小化（PIPL）

- 精确家庭地址→商圈级（`party_constraints.origin_area`）；个人预算→仅参与聚合、默认不外显；证件号不落库（回填时打码，DD-10）。
- `users` 主表无手机号/真实姓名；如需通知，联系方式单独加密表 + 显式授权。

### 11.2 保留 / TTL

| 数据 | 保留策略 |
|---|---|
| screenshots | 7 天（OSS 生命周期） |
| raw_pages.clean_md | 保留最新若干版，历史归档/清理 |
| checkpoints | 行程结束 7 天后归档；60 天无活动软过期 |
| reminders | 发送后保留 90 天 |

### 11.3 checkpoint 生命周期（对应 v1 §14 “长周期 interrupt 状态膨胀”）

- 计划进入 confirm 且行程结束 7 天后：归档 checkpoint。
- 60 天无活动的 explore/await_booking：软过期，提示用户或清理。

### 11.4 用户数据权利

- 一键导出（plans+bundles+context 的 JSON）、一键删除（级联 `ON DELETE CASCADE`）。

## 16. v2 增补：对话 / 记忆 / 实时深研的数据模型（对齐 v2 增补 + DD-15/16/17）

```sql
-- 16.1 用户长期语义记忆（DD-16 写/读；权威定义在 DD-16 §3）
CREATE TABLE user_memory (
  id          BIGSERIAL PRIMARY KEY,
  user_id     BIGINT REFERENCES users(id) ON DELETE CASCADE,
  mem_type    TEXT NOT NULL,              -- preference/fact/episodic
  key         TEXT,                       -- 归一化键(diet/origin_city/budget/interest)，用于覆盖
  content     TEXT NOT NULL,
  embedding   VECTOR(1024),
  confidence  REAL DEFAULT 0.7,
  source_plan_id BIGINT,
  valid       BOOLEAN DEFAULT TRUE,       -- 覆盖时旧记忆置 FALSE（软失效、可回溯）
  created_at  TIMESTAMPTZ DEFAULT now(),
  updated_at  TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX ON user_memory USING hnsw (embedding vector_cosine_ops);
CREATE INDEX ON user_memory (user_id, mem_type, valid);

-- 16.2 实时深研作业与缓存（DD-17 写/读；权威定义在 DD-17 §5）
CREATE TABLE deep_research_jobs (
  id BIGSERIAL PRIMARY KEY, plan_id BIGINT REFERENCES plans(id) ON DELETE CASCADE,
  trigger TEXT NOT NULL, query JSONB NOT NULL, status TEXT DEFAULT 'running',
  found_activity_ids BIGINT[], source_count INT DEFAULT 0, official_count INT DEFAULT 0,
  started_at TIMESTAMPTZ DEFAULT now(), finished_at TIMESTAMPTZ, error TEXT
);
CREATE TABLE deep_research_cache (
  query_hash TEXT PRIMARY KEY, result_ids BIGINT[], source_list JSONB,
  created_at TIMESTAMPTZ DEFAULT now(), expires_at TIMESTAMPTZ
);

-- 16.3 plans 增会话快照（多轮消息；权威会话状态仍在 LangGraph checkpoint）
ALTER TABLE plans ADD COLUMN conversation JSONB DEFAULT '[]';
```
