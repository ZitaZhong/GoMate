# DD-11 住宿区域 · 市内交通接驳 · 餐饮（先区域后酒店 / 动线餐饮）· 详细设计

**详细设计系列 · 领域节点文档 · v1.0 · 2026 年 7 月**

> 本文定义 DD-02 图拓扑中**确认阶段**的三个连续节点 —— `hotel`（住宿区域决策）、`mobility`（市内逐段接驳）、`dining`（动线餐饮安排）—— 的完整实现。三节点在 `await_booking` 恢复后依次执行（`hotel → mobility → dining → timeline`），把"住哪片区域、每段怎么走、饭点在哪吃"三件事变成**带证据、可解释、可调试**的确定性产物，供 DD-12 时间线求解与 DD-13 组装消费。
>
> **上游依据**：v1 §9.4（`recommend_lodging_area` 住宿区域决策）、§5.7/§5.8（餐饮动线 + 市内接驳）、§2.6（餐饮以高德 POI 为主 + BYO 链接）；v1.1 增补 A（餐饮召回后按"动线契合 + 偏好 + 忌讳"重排，修"找餐馆不妥帖"）；DD-01（`dining_picks`/`route_legs` 表、`city_playbook.lodging_areas`、`bookings`、`evidence` JSONB 规范）；DD-02 §5（三节点读写契约、受 Guard、降级行为）；DD-03 §5/§6（`restaurant.open_hours`/`restaurant.phone`/`route.minutes` 来源白名单与 `enforce_provenance`）；DD-04（高德 `poi_search`/`route`/`distance_matrix`，禁裸调）；DD-05（`retrieve_dining` 混合召回 + 重排）；DD-09（返程枢纽来自 `transport_options`/`bookings`）；DD-10（`bookings` 提供已确认酒店与返程车站/机场）；PRD 5.6/5.7/5.8。
> **下游消费者**：DD-12（`timeline` 消费 `local_routes`/`dining`/`hotel_area`）、DD-13（确认版 bundle 渲染住宿区域卡/餐饮卡/市内路线，起提醒）、前端。
> **三条硬约束落地**：① **不做交易**（住宿只出"区域卡 + 筛选清单 + 平台搜索入口"，酒店由用户在平台选定后经 DD-10 回填；餐饮只给候选 + 电话，不订座、不比价）；② **证据优先**（营业时间/电话带来源 `amap`→`public_source_observed`；路线耗时 `amap`→`observed`、`rule`→`estimated`；一律经 DD-03 `enforce_provenance`）；③ **轻后端重证据**（区域打分、逐段接驳、饭点安排都是可解释的确定性计算，探索期粗估、城市定后精算）。
> **差异化落地**：住宿 **先定区域再定酒店**（好决策 80% 是区域决策）；餐饮 **安排在动线上**（按活动/返程时间在正确位置给候选，按距离动线契合度重排，而非丢一个评分榜单）。

## 1. 模块职责与边界（实现 `hotel` / `mobility` / `dining` 三节点）

| 项 | 说明 |
|---|---|
| **职责** | 实现 DD-02 确认阶段三个确定性节点：`hotel` 对城市档案候选住宿区域打分，产出**住宿区域卡**（区域 + 理由 + ETA + 筛选清单 + 平台搜索入口）；`mobility` 对"家→车站/机场→酒店→活动→餐厅→返程枢纽"逐段用高德算耗时距离，产出 `route_legs`；`dining` 调 DD-05 `retrieve_dining` 按活动/返程时间在动线上安排饭点，每餐 2–3 候选 + 1 稳妥备选，标注菜系/人均/营业时间/电话。 |
| **边界内** | `recommend_lodging_area` 区域打分与区域卡装配、`build_hotel_filters`/搜索入口、返程枢纽解析（`resolve_return_hub`）、`build_route_legs` 逐段接驳（高德 `route`/`distance_matrix` + 直线降级）、`plan_dining` 饭点锚点计算 + `retrieve_dining` 调用 + 备选保留、三张产物的 `evidence` 定级（经 DD-03）、三节点入口函数与 `state` 装配、写 `dining_picks`/`route_legs` 表。 |
| **边界外** | ① 不做时间线求解与硬约束校验（DD-12）；② 不实现 Provider 五件套与 POI 召回底座（DD-04/DD-05，本模块只调用）；③ 不写 `activities`（只读，读写解耦）；④ 不做交通策略/门到门/起售提醒（DD-09）；⑤ 不做酒店回填抽取与确认（DD-10，本模块只**消费**已确认酒店）；⑥ 不定证据白名单规则（DD-03，本模块只调 `enforce_provenance`）。 |
| **架构位置** | v1 §4.1「领域服务层（确定性）· 住宿区域决策 / 市内交通接驳 / 餐饮」；DD-02 图节点 `await_booking →(resume)→ hotel → mobility → dining → timeline`。 |

**三节点契约（对齐 DD-02 §5，逐字一致）**：

| 节点 | 读入 state 字段 | 写出 state 字段 | 调用（模块/Provider） | 受 Guard | 降级行为 |
|---|---|---|---|---|---|
| `hotel` | `bookings`, `candidate_cities`(选定城) | `hotel_area`, `warnings` | DD-11；DD-04 map(`distance_matrix`/`route`) | 是（区域卡字段带 evidence） | 无 POI→区域 + 筛选条件 |
| `mobility` | `bookings`, `hotel_area`, `activities`(选定) | `local_routes`, `warnings` | DD-11；DD-04 map(`route`/`distance_matrix`) | 是（`source=amap/rule`） | 额度受限→缓存 + 地图链接 |
| `dining` | `timeline`(草稿), `hotel_area`, `constraints` | `dining`, `warnings` | DD-11；DD-05 `retrieve_dining` 重排；DD-04 `poi_search` | 是（营业时间带来源） | POI 不足→区域 + 稳妥备选 |

> **读写解耦铁律**：三节点对 `activities` **只读**；`bookings` 只由 `await_booking` 经 resume 注入（写来自 DD-10 用户确认）；本模块仅写 `route_legs`/`dining_picks` 两张业务表（DD-01 §13 归属矩阵），`hotel_area` 仅入 `state`（无独立业务表，随 bundle 快照落 `trip_bundles`）。

## 2. 设计目标与非目标

**目标**：
1. **先区域后酒店**：住宿决策产出**区域卡**而非酒店列表——对 `city_playbook.lodging_areas` 候选区域按"到核心活动 ETA + 到返程枢纽 ETA + 餐饮密度 − 夜间交通风险"打分，给出理由、双向 ETA、筛选清单与平台搜索入口；酒店由用户在平台选定后经 DD-10 回填，本节点若检测到 `bookings` 已有确认酒店则直接标注 `hotel_confirmed`。
2. **门到门逐段接驳**：把整条动线拆成有序 `route_legs`（家→车站/机场→酒店→活动→餐厅→返程枢纽），每段用高德 `route` 算真实耗时距离，标 `source`；探索期用 `distance_matrix`/直线粗估，城市定后精算——成本可控且可解释。
3. **动线餐饮，非榜单**：按活动结束时刻与返程时间确定饭点锚点（午/晚/咖啡），在锚点附近调 DD-05 `retrieve_dining`（POI 召回 → 按"距离动线契合 + 偏好 + 忌讳"重排），每餐 2–3 候选 + **永远 1 个稳妥备选**（`is_fallback`），并支持用户 BYO 收藏链接接入候选池。
4. **证据优先**：营业时间/电话来自高德 → `public_source_observed`；路线耗时高德 → `observed`、降级规则 → `estimated`；所有对外事实经 DD-03 `enforce_provenance`，绝不由 LLM 编造营业时间/电话/耗时。
5. **确定性、可单测**：区域打分、接驳计算、饭点安排均为纯函数 + 注入 Provider/检索服务，mock 掉 `state` 读入字段与依赖即可独立测试。

**非目标**：
- ❌ 不推荐/预订具体酒店（只出区域卡与搜索入口，不做交易，不碰账户）。
- ❌ 不做餐厅订座、不比价、不抓点评榜单（只用高德 POI 事实 + 用户 BYO 链接）。
- ❌ 不让 LLM 生成营业时间/电话/路线耗时（受 DD-03 白名单约束，缺来源即 `unknown`/`estimated`）。
- ❌ 不做时间线排点（DD-12）；本节点 `dining` 只读 DD-12 产出的**时间线草稿**定饭点锚点，不反向排程。

## 3. 数据模型（`hotel_area` / `route_legs` / `dining_picks`；表结构引用 DD-01）

> 表 DDL 一律以 DD-01 §8.3/§8.4 为准，本文**不重复 DDL**，只定义 `state` DTO 与落库字段语义、供 DD-12 消费的权威结构。时区 `Asia/Shanghai`；金额单位分（`INT`）；坐标 `{lng,lat}`（WGS84/GCJ02 与高德一致，落库转 `GEOGRAPHY(Point,4326)`）。

### 3.2 `route_legs`（DD-01 §8.4；本模块唯一写；`state["local_routes"]` 追加）

`state["local_routes"]` 为 `Annotated[list[dict], operator.add]`（DD-02 §3，并行安全追加）；每段结构与 `route_legs` 表行一一对应：

```jsonc

  "from_label": "北京南站", "to_label": "东四某某酒店",
  "from_geo": {"lng": 116.378, "lat": 39.865},
  "to_geo":   {"lng": 116.42,  "lat": 39.925},
  "mode": "transit",                     // walk | transit | drive | taxi（DD-01 §8.4）
  "minutes": 35,                         // route.minutes；amap→observed / rule→estimated
  "distance_m": 12000,                   // route.distance_m
  "map_url": "https://uri.amap.com/navigation?from=116.378,39.865&to=116.42,39.925&mode=bus",
  "evidence": {                          // DD-03：amap→public_source_observed / rule→estimated
    "source_type": "amap",
    "verification_status": "public_source_observed",
    "source_url": null, "note": null

```

> `map_url` 供前端与降级场景兜底（"打开地图看这段"）；`evidence` 由 `enforce_provenance("route.minutes", ...)` 定级，`minutes`/`distance_m` 同源同级。`from_geo`/`to_geo` 落库为 `GEOGRAPHY(Point,4326)`。

## 4. 接口契约

> 所有对外/跨模块函数签名。外部访问经 DD-04 `ResilientProvider`（**禁裸调**）；检索经 DD-05 `RetrievalService`；证据经 DD-03 `enforce_provenance`（**禁绕过**）。三节点为同步节点（LangGraph），内部 `asyncio.run` 驱动 async 子调用。

```python
from __future__ import annotations
from dataclasses import dataclass
from datetime import datetime

# —— 依赖注入：DD-04 Provider + DD-05 检索服务句柄 ——
@dataclass
class LocalDeps:
    amap: "ResilientProvider"            # name='amap'：geocode / route / distance_matrix / poi_search
    retrieval: "RetrievalService"        # DD-05：retrieve_dining
    clock: "callable" = datetime.now     # 便于测试注入固定时钟

# ============ hotel 节点 ============
def hotel_area_planning(state: "TripPlanState", deps: LocalDeps) -> dict:
    """读 bookings/candidate_cities(选定城)，写 hotel_area + warnings。
    返回 {"hotel_area": {...}, "warnings": [...]}。"""

def resolve_return_hub(bookings: list[dict], transport_options: dict,
                       selected_city: dict) -> dict:
    """返程枢纽解析：优先 bookings 已确认返程车站/机场（DD-10），否则取 DD-09 顶选门到门
    的 dest_station。返回 {"name","type","location","source"}。"""

def recommend_lodging_area(city: dict, activities: list[dict], return_hub: dict,
                           constraints: dict, deps: LocalDeps,
                           top_n: int = 3) -> list[dict]:
    """v1 §9.4：对 city.lodging_areas 候选区域打分，返回 top_n 住宿区域卡（含双向 ETA/理由/筛选/入口）。"""

def build_hotel_filters(area: dict, constraints: dict) -> dict:
    """据区域与约束生成酒店筛选清单（晚到可入住/免费取消/寄存/预算上限/近地铁）。"""

def build_search_entry(area: dict, city_code: str) -> dict:
    """生成平台搜索入口（携程/美团/高德深链）+ 关键词，不做交易。"""

# ============ mobility 节点 ============
def local_mobility(state: "TripPlanState", deps: LocalDeps) -> dict:
    """读 bookings/hotel_area/activities(选定)，写 local_routes + warnings。
    返回 {"local_routes": [...], "warnings": [...]}。"""

def build_itinerary_points(state: "TripPlanState") -> list[dict]:
    """把动线拆成有序途经点：家/出发地→到达车站/机场→酒店→活动…→餐厅→返程枢纽。
    返回 [{"label","geo","kind"}]，供逐段成对计算。"""
```

```python
def _haversine_m(frm: dict, to: dict) -> int:
    """两坐标直线距离（米）。用于降级估算与最近点选择。"""
    R = 6371000.0
    dlat = math.radians(to["lat"] - frm["lat"]); dlng = math.radians(to["lng"] - frm["lng"])
    a = (math.sin(dlat / 2) ** 2
         + math.cos(math.radians(frm["lat"])) * math.cos(math.radians(to["lat"]))
         * math.sin(dlng / 2) ** 2)
    return int(2 * R * math.asin(math.sqrt(a)))

def _straight_line_minutes(frm: dict, to: dict, kmph: float = 20.0) -> int:
    """直线距离 / 经验市内车速（默认 20km/h）→ 分钟。降级用，标 rule/estimated。"""
    return max(5, round(_haversine_m(frm, to) / 1000 / kmph * 60))

def _amap_map_url(frm: dict, to: dict, mode: str) -> str:
    m = {"walk": "walk", "transit": "bus", "drive": "car", "taxi": "car"}.get(mode, "bus")
    return (f"https://uri.amap.com/navigation?from={frm['lng']},{frm['lat']}"
            f"&to={to['lng']},{to['lat']}&mode={m}")
```

### 5.1 返程枢纽解析（来自 `bookings` / `transport_options`，DD-09/DD-10）

```python
def resolve_return_hub(bookings: list[dict], transport_options: dict,
                       selected_city: dict) -> dict:
    """返程枢纽（住宿打分的关键输入）。优先级：
    ① bookings 已确认的返程车次/航班的出发站（confirmed_by_user，最可信）；
    ② DD-09 transport_options 顶选候选城的门到门 dest_station（返程方向的枢纽）；
    ③ 兜底：城市档案第一个 rail 站。"""
    # ① 已确认返程（DD-10）：train/flight 中时间最晚的一段的出发站即返程枢纽
    returns = [b for b in bookings
               if b.get("confirmed") and b["kind"] in ("train", "flight")]
    if returns:
        latest = max(returns, key=lambda b: _dep_dt(b))
        f = latest["extracted"]["fields"]
        name = (f.get("from_station") or f.get("dep_airport") or {}).get("value")
        stations = selected_city.get("playbook", {}).get("stations", [])
        st = next((s for s in stations if s["name"] == name or name in s["name"]), None)
        if st:
            return {"name": st["name"], "type": st["type"],
                    "location": st["location"], "source": "booking"}
    # ② DD-09 顶选门到门 dest_station（返程用同名枢纽）
    cands = (transport_options or {}).get("candidates", [])
    top = next((c for c in cands if c.get("city_code") == selected_city.get("city_code")), None)
    if top:
        d2d = (top.get("door_to_door") or {})
        chosen = d2d.get("rail") or d2d.get("air")
        if chosen and chosen.get("dest_station"):
            stations = selected_city.get("playbook", {}).get("stations", [])
            st = next((s for s in stations if s["name"] == chosen["dest_station"]), None)
            if st:
                return {"name": st["name"], "type": st["type"],
                        "location": st["location"], "source": "transport_options"}
    # ③ 兜底：档案第一个 rail 站
    rails = [s for s in selected_city.get("playbook", {}).get("stations", [])
             if s.get("type") == "rail"]
    st = rails[0] if rails else {"name": "返程枢纽", "type": "rail", "location": selected_city["core_geo"]}
    return {"name": st["name"], "type": st.get("type", "rail"),
            "location": st["location"], "source": "transport_options"}

def _dep_dt(booking: dict) -> datetime:
    f = booking["extracted"]["fields"]
    d = f["date"]["value"]; t = (f.get("depart") or f.get("dep_time") or {}).get("value", "00:00")
    return datetime.fromisoformat(f"{d}T{t}:00+08:00")
```

### 5.2 住宿区域打分（v1 §9.4 `recommend_lodging_area`，确定性可解释）

```python
# 打分权重（§9 可配置）。归一后线性加权：距离越近越好（取倒数），密度越高越好，夜间风险越高越差。
LODGING_WEIGHTS = {"w_act": 0.35, "w_hub": 0.25, "w_dining": 0.25, "w_night": 0.15}
ETA_CAP_MIN = 90     # ETA 归一上限（超过按 90min 截断，避免离群值主导）

def _norm_inv_eta(eta_min: int) -> float:
    """ETA 归一为 0~1 的"近度"（越近越接近 1）。"""
    e = min(max(eta_min, 1), ETA_CAP_MIN)
    return 1.0 - (e - 1) / (ETA_CAP_MIN - 1)

async def _eta_minutes(deps: LocalDeps, frm: dict, to: dict,
                       precise: bool) -> tuple[int, str]:
    """区域→活动/枢纽 ETA。precise=True 用高德 route；否则 distance_matrix/直线粗估。
    返回 (minutes, source)。"""
    if precise:
        m, _d, src, _n = await _amap_leg(deps, frm, to, mode="transit")
        return m, src
    # 探索期：distance_matrix 批量粗估（成本低），失败→直线
    req = Req(op="distance_matrix",
              params={"origins": f"{frm['lng']},{frm['lat']}",
                      "destinations": f"{to['lng']},{to['lat']}", "mode": "transit"},
              cache_ttl=7 * 86400)
    r = await deps.amap.call(req)
    if r.ok and r.data and r.data.get("duration_minutes") is not None:
        return int(r.data["duration_minutes"]), "amap"
    return _straight_line_minutes(frm, to), "rule"

def recommend_lodging_area(city: dict, activities: list[dict], return_hub: dict,
                           constraints: dict, deps: LocalDeps, top_n: int = 3) -> list[dict]:
    areas = city.get("playbook", {}).get("lodging_areas", []) or city.get("lodging_areas", [])
    act_geos = [a["location"] for a in activities if a.get("location")]
    hub_geo = return_hub["location"]
    W = LODGING_WEIGHTS
    # 城市定后精算（precise=True），探索期粗估（precise=False）——由是否已选定城市决定
    precise = bool(city.get("selected"))

    async def _score_one(area: dict) -> dict:
        center = area["center"]
        # 到各活动 ETA 取平均（无活动→与枢纽等权兜底）
        if act_geos:
            etas = await asyncio.gather(*[_eta_minutes(deps, center, g, precise) for g in act_geos])
            t_act = round(sum(m for m, _ in etas) / len(etas)); src_act = _mode_src([s for _, s in etas])
        else:
            t_act, src_act = 30, "rule"
        t_hub, src_hub = await _eta_minutes(deps, center, hub_geo, precise)
        density = float(area.get("dining_density", 0.5))
        night = float(area.get("night_transit_risk", 0.3))
        score = (W["w_act"] * _norm_inv_eta(t_act)
                 + W["w_hub"] * _norm_inv_eta(t_hub)
                 + W["w_dining"] * density
                 - W["w_night"] * night)
        return {
            "area": area["name"], "center": center, "score": round(score, 4),
            "reason": _area_reasons(t_act, t_hub, density, night, return_hub),
            "eta_to_activities": _eta_fact(t_act, src_act),
            "eta_to_hub": _eta_fact(t_hub, src_hub),
            "dining_density": density, "night_transit_risk": night,
            "filters": build_hotel_filters(area, constraints),
            "search_entry": build_search_entry(area, city.get("city_code", "")),
        }

    scored = asyncio.run(asyncio.gather(*[_score_one(a) for a in areas])) if areas else []
    return sorted(scored, key=lambda x: -x["score"])[:top_n]

def _eta_fact(minutes: int, source: str) -> dict:
    """ETA 经 DD-03 定级：amap→observed，rule→estimated。route.minutes 白名单允许。"""
    fact = enforce_provenance("route.minutes", minutes, source)
    return {"value": minutes, "evidence": _ev_dict(fact.evidence)}

def _mode_src(sources: list[str]) -> str:
    """多段来源汇总：只要有一段是 rule（降级），整体标 rule（保守）。"""
    return "rule" if any(s == "rule" for s in sources) else "amap"

def _area_reasons(t_act: int, t_hub: int, density: float, night: float, hub: dict) -> list[str]:
    r = [f"到核心活动约 {max(t_act-5,5)}–{t_act+5} 分钟"]
    r.append("晚餐选择多（餐饮密度高）" if density >= 0.6 else "餐饮选择一般，可搭配 BYO 收藏")
    r.append(f"去{hub['name']}约 {t_hub} 分钟"
             + ("，返程相对稳定" if night < 0.4 else "，注意夜间交通"))
    return r

def build_hotel_filters(area: dict, constraints: dict) -> dict:
    budget = constraints.get("budget_band", {})
    # 两间房总价上限：取预算区间上限（元）→ 分；无则不限
    budget_max_cent = int(budget["max"] * 100) if budget.get("max") else None
    return {"checkin_after": "23:30", "free_cancel": True, "luggage_storage": True,
            "budget_max_cent": budget_max_cent, "near_transit": True}

def build_search_entry(area: dict, city_code: str) -> dict:
    kw = area["name"]
    return {"keywords": [f"{kw} 酒店", "免费取消", "可寄存行李"],
            "platforms": [
                {"name": "携程", "url": f"https://hotels.ctrip.com/hotels/list?city={city_code}&kw={kw}"},
                {"name": "美团", "url": f"https://i.meituan.com/hotel/search?q={kw}"},
                {"name": "高德", "url": f"https://uri.amap.com/search?keyword={kw}酒店"}]}
```

### 5.4 市内接驳逐段计算（`mobility` 节点；探索粗估 / 精算）

```python
def local_mobility(state: "TripPlanState", deps: LocalDeps) -> dict:
    warnings: list[str] = []
    hotel_area = state.get("hotel_area", {})
    if not hotel_area:
        return {"local_routes": [], "warnings": ["无住宿区域，跳过接驳计算"]}
    points = build_itinerary_points(state)
    if len(points) < 2:
        return {"local_routes": [], "warnings": ["途经点不足，无法计算接驳"]}
    precise = bool(_pick_selected_city(state))           # 城市已定→精算，否则粗估
    legs = asyncio.run(build_route_legs(deps, points, precise=precise))
    # 降级统计
    if any(l["evidence"]["source_type"] == "rule" for l in legs):
        warnings.append("部分接驳段地图额度受限，已用直线估算并附地图链接")
    return {"local_routes": legs, "warnings": warnings}

def build_itinerary_points(state: "TripPlanState") -> list[dict]:
    """动线途经点：出发地→到达车站/机场→酒店/区域→活动(按草稿序)→返程枢纽。
    坐标缺失的点跳过；酒店未定用区域中心；活动取选定且有坐标者。"""
    pts: list[dict] = []
    ha = state["hotel_area"]
    bookings = state.get("bookings", [])
    # 到达车站/机场（去程 booking 的到达站）——若已确认
    arr = _arrival_station_geo(bookings, state)
    if arr:
        pts.append({"label": arr["name"], "geo": arr["location"], "kind": "hub"})
    # 酒店（已确认坐标）或区域中心
    hotel = ha.get("confirmed_hotel")
    if hotel and hotel.get("location"):
        pts.append({"label": hotel["name"], "geo": hotel["location"], "kind": "hotel"})
    else:
        area = next((a for a in ha.get("recommended_areas", [])
                     if a["area"] == ha.get("selected_area")), None)
        if area:
            pts.append({"label": f'{area["area"]}(住宿区域)', "geo": area["center"], "kind": "area"})
    # 活动（按时间线草稿顺序；无草稿则按 start_at）
    for a in _selected_activities(state):
        if a.get("location"):
            pts.append({"label": a.get("title", "活动"), "geo": a["location"], "kind": "activity"})
    # 返程枢纽
    hub = ha.get("return_hub")
    if hub:
        pts.append({"label": hub["name"], "geo": hub["location"], "kind": "return_hub"})
    return pts

async def build_route_legs(deps: LocalDeps, points: list[dict], *, precise: bool) -> list[dict]:
    legs: list[dict] = []
    for seq, (frm, to) in enumerate(zip(points, points[1:])):
        mode = _pick_mode(frm, to)                       # 距离/类型推荐 walk/transit/drive
        if precise:
            minutes, dist_m, source, _note = await _amap_leg(deps, frm["geo"], to["geo"], mode)
        else:
            minutes = _straight_line_minutes(frm["geo"], to["geo"]); source = "rule"
            dist_m = _haversine_m(frm["geo"], to["geo"])
        fact = enforce_provenance("route.minutes", minutes, source)   # amap→observed / rule→estimated
        legs.append({
            "seq": seq, "from_label": frm["label"], "to_label": to["label"],
            "from_geo": frm["geo"], "to_geo": to["geo"], "mode": mode,
            "minutes": minutes, "distance_m": dist_m,
            "map_url": _amap_map_url(frm["geo"], to["geo"], mode),
            "evidence": _ev_dict(fact.evidence),
        })
    return legs

async def _amap_leg(deps: LocalDeps, frm: dict, to: dict,
                    mode: str) -> tuple[int, int, str, str]:
    """高德 route（禁裸调，7 天缓存）；失败→直线估算(rule)。返回 (minutes, distance_m, source, note)。"""
    req = Req(op="route",
              params={"origin": f"{frm['lng']},{frm['lat']}",
                      "destination": f"{to['lng']},{to['lat']}", "mode": mode},
              cache_ttl=7 * 86400)
    r = await deps.amap.call(req)
    if r.ok and r.data and r.data.get("duration_minutes") is not None:
        return (int(r.data["duration_minutes"]),
                int(r.data.get("distance_m", _haversine_m(frm, to))),
                "amap", "降级路径" if r.degraded else "高德路线")
    return _straight_line_minutes(frm, to), _haversine_m(frm, to), "rule", "地图额度受限→直线估算"

def _pick_mode(frm: dict, to: dict) -> str:
    """按直线距离粗选出行方式：<1.2km 步行；<15km 公交；否则驾车/打车。"""
    d = _haversine_m(frm["geo"], to["geo"])
    if d < 1200: return "walk"
    if d < 15000: return "transit"
    return "drive"
```

```python
        if group.get("degraded"):
            warnings.append(f"{anchor['meal_slot']}：POI 不足，已给区域 + 稳妥备选")
        dining.append(group)
    return {"dining": dining, "warnings": warnings}

def plan_dining_anchors(timeline_draft: list[dict], hotel_area: dict,
                        constraints: dict) -> list[dict]:
    """据时间线草稿的活动落点与返程时刻，确定午/晚（必要时咖啡）锚点。
    锚点 near = 该时段最近活动坐标；无活动→住宿区域中心。"""
    anchors: list[dict] = []
    area_center = _selected_area_center(hotel_area)
    acts = _acts_from_draft(timeline_draft)              # [{title,id,at,geo}]，按 at 排序
    for slot, (h1, m1, h2, m2) in MEAL_WINDOWS.items():
        if slot == "coffee" and not _needs_coffee(acts):   # 咖啡按需
            continue
        near, after = _nearest_act_in_window(acts, h1, m1, h2, m2)
        anchors.append({
            "meal_slot": slot,
            "at": _slot_time(acts, h1, m1),               # 建议就餐时刻（时段起点或活动结束后）
            "near": near or area_center,
            "after_ref": after,                            # {"table":"activities","id","title"} | None
        })
    # 若无任何活动坐标，至少保留午/晚两餐锚在住宿区域
    return [a for a in anchors if a["near"]]

async def fill_dining_candidates(deps: LocalDeps, anchor: dict, constraints: dict,
                                 byo_links: list[dict], top_k: int = 3) -> dict:
    """调 DD-05 retrieve_dining（POI 召回→动线契合+偏好+忌讳重排）+ BYO + 恒 1 稳妥备选。"""
    degraded = False
    try:
        cands = await deps.retrieval.retrieve_dining(
            near=anchor["near"], meal_slot=anchor["meal_slot"],
            constraints=constraints, top_k=top_k)
    except Exception:
        cands, degraded = [], True

    picks: list[dict] = []
    for c in cands[:top_k]:
        picks.append(_candidate_to_pick(c, anchor))
    # 合入 BYO 收藏链接（用户粘贴的点评/小红书链接→位置对齐后作候选）
    for link in byo_links:
        bp = _byo_to_pick(link, anchor, deps)
        if bp:
            picks.append(bp)
    # 恒附一个稳妥备选（若检索候选里已带 is_fallback 则复用，否则构造）
    has_fb = any(p.get("is_fallback") for p in picks)
    if not has_fb:
        picks.append(build_fallback_pick(anchor, hotel_area=None))
    if not cands:
        degraded = True
    return {"meal_slot": anchor["meal_slot"], "anchor": anchor,
            "candidates": picks, "degraded": degraded}

def _candidate_to_pick(c: "DiningCandidate", anchor: dict) -> dict:
    """DD-05 候选 → §3.3 pick。营业时间/电话经 DD-03 定级（amap→observed，缺→unknown）。"""
    oh = enforce_provenance("restaurant.open_hours", getattr(c, "open_hours", None), "amap")
    ph = enforce_provenance("restaurant.phone", getattr(c, "phone", None), "amap")
    dist = _haversine_m(anchor["near"], c.location) if c.location else None
    return {
        "amap_poi_id": c.amap_poi_id, "name": c.name, "location": c.location,
        "cuisine": getattr(c, "cuisine", None),
        "price_band": {"per_capita_cent": getattr(c, "per_capita_cent", None)},
        "open_hours": {"value": oh.value, "evidence": _ev_dict(oh.evidence)},
        "phone": {"value": ph.value, "evidence": _ev_dict(ph.evidence)},
        "distance_m": dist, "rerank_score": getattr(c, "rerank_score", None),
        "is_fallback": getattr(c, "is_fallback", False), "source": "amap",
        "evidence": _ev_dict(oh.evidence),   # 行级证据取营业时间（对外关键事实）
    }

def build_fallback_pick(anchor: dict, hotel_area: dict | None) -> dict:
    """无 POI/检索空→稳妥备选：区域连锁/酒店周边，不编造营业时间/电话（unknown）。"""
    oh = enforce_provenance("restaurant.open_hours", None, "rule")   # 无来源→estimated/unknown
    return {"amap_poi_id": None, "name": "稳妥备选：住宿区域周边餐饮",
            "location": anchor.get("near"), "cuisine": None,
            "price_band": {"per_capita_cent": None},
            "open_hours": {"value": None, "evidence": _ev_dict(oh.evidence)},
            "phone": {"value": None, "evidence": _ev_dict(oh.evidence)},
            "distance_m": 0, "rerank_score": None, "is_fallback": True, "source": "rule",
            "evidence": _ev_dict(oh.evidence),
            "note": "该时段附近 POI 不足，建议到住宿区域周边就近选择"}

def _byo_to_pick(link: dict, anchor: dict, deps: LocalDeps) -> dict | None:
    """BYO 收藏链接：用高德 poi_search 按店名对齐坐标（PRD 5.7 收藏夹入行程）。"""
    name = link.get("name")
    if not name:
        return None
    loc = asyncio.run(_poi_locate(deps, name, anchor["near"]))
    oh = enforce_provenance("restaurant.open_hours",
                            (loc or {}).get("open_hours"), "amap" if loc else "rule")
    ph = enforce_provenance("restaurant.phone", (loc or {}).get("phone"), "amap" if loc else "rule")
    return {"amap_poi_id": (loc or {}).get("amap_poi_id"), "name": name,
            "location": (loc or {}).get("location"), "cuisine": link.get("cuisine"),
            "price_band": {"per_capita_cent": None},
            "open_hours": {"value": oh.value, "evidence": _ev_dict(oh.evidence)},
            "phone": {"value": ph.value, "evidence": _ev_dict(ph.evidence)},
            "distance_m": _haversine_m(anchor["near"], (loc or {}).get("location")) if loc else None,
            "rerank_score": None, "is_fallback": False, "source": "byo",
            "evidence": _ev_dict(oh.evidence)}

async def _poi_locate(deps: LocalDeps, name: str, near: dict) -> dict | None:
    req = Req(op="poi_search",
              params={"keywords": name, "location": f"{near['lng']},{near['lat']}",
                      "radius": 3000, "types": "餐饮服务"},
              cache_ttl=3 * 86400)     # POI 3 天缓存（DD-04 §4.1）
    r = await deps.amap.call(req)
    if r.ok and r.data and r.data.get("pois"):
        p = r.data["pois"][0]
        return {"amap_poi_id": p.get("id"), "location": p.get("location"),
                "open_hours": p.get("open_hours"), "phone": p.get("tel")}
    return None
```

### 5.6 节点内公共 helper（选定城/选定活动/时间线草稿解析）

```python
def _pick_selected_city(state: "TripPlanState") -> dict | None:
    """选定城市：candidate_cities 中标 selected=True 者；否则排序第一（discover 顶选）。"""
    cands = state.get("candidate_cities", [])
    if not cands:
        return None
    return next((c for c in cands if c.get("selected")), cands[0])

def _selected_activities(state: "TripPlanState") -> list[dict]:
    """选定活动：activities 中标 selected 或全部（首轮）；只保留有坐标者。"""
    acts = state.get("activities", [])
    chosen = [a for a in acts if a.get("selected")] or acts
    return [a for a in chosen if a.get("location")]

def _selected_area_center(hotel_area: dict) -> dict | None:
    for a in hotel_area.get("recommended_areas", []):
        if a["area"] == hotel_area.get("selected_area"):
            return a["center"]
    hotel = hotel_area.get("confirmed_hotel")
    return (hotel or {}).get("location")

def _acts_from_draft(timeline_draft: list[dict]) -> list[dict]:
    """从 DD-12 时间线草稿抽活动落点；草稿为空→返回空（plan_dining_anchors 用区域兜底）。"""
    out = []
    for s in timeline_draft:
        if s.get("kind") == "activity" and s.get("geo"):
            out.append({"title": s.get("title"), "id": s.get("ref_id"),
                        "at": s.get("end_at") or s.get("start_at"), "geo": s["geo"]})
    return sorted(out, key=lambda x: x["at"] or "")

def _arrival_station_geo(bookings: list[dict], state: "TripPlanState") -> dict | None:
    """去程到达站坐标（已确认 booking 的 to_station/arr_airport → 档案坐标）。"""
    city = _pick_selected_city(state) or {}
    stations = city.get("playbook", {}).get("stations", [])
    arrivals = [b for b in bookings if b.get("confirmed") and b["kind"] in ("train", "flight")]
    if not arrivals:
        return None
    earliest = min(arrivals, key=lambda b: _dep_dt(b))     # 去程=最早一段
    f = earliest["extracted"]["fields"]
    name = (f.get("to_station") or f.get("arr_airport") or {}).get("value")
    st = next((s for s in stations if name and (s["name"] == name or name in s["name"])), None)
    return {"name": st["name"], "location": st["location"]} if st else None

def _nearest_act_in_window(acts, h1, m1, h2, m2):
    """时段内最近结束的活动作为饭点 near 与 after_ref。"""
    lo = f"{h1:02d}:{m1:02d}"; hi = f"{h2:02d}:{m2:02d}"
    in_win = [a for a in acts if a["at"] and lo <= a["at"][11:16] <= hi]
    if in_win:
        a = in_win[-1]
        return a["geo"], {"table": "activities", "id": a["id"], "title": a["title"]}
    return (acts[-1]["geo"] if acts else None), None

def _slot_time(acts, h, m) -> str | None:
    base = acts[0]["at"][:10] if acts and acts[0]["at"] else None
    return f"{base}T{h:02d}:{m:02d}:00+08:00" if base else None

def _needs_coffee(acts: list[dict]) -> bool:
    """午晚之间活动跨度大（>3h 无餐）时安排咖啡/下午茶。"""
    return len(acts) >= 3
```

## 6. 与其他模块接线

> 本模块处在 DD-02 图拓扑 `await_booking →(resume)→ hotel → mobility → dining → timeline` 的确认阶段，上承 booking 回填、下启时间线求解。所有跨模块调用**只走契约接口**，不越层访问对方内部实现。

### 6.1 接线总表

| 对端模块 | 方向 | 契约点 | 用途 |
|---|---|---|---|
| **DD-01** 数据模型 | 写 | `route_legs` 表（§8.4）、`dining_picks` 表（§8.3） | mobility/dining 落库；`hotel_area` 随 bundle 快照落 `trip_bundles`，无独立表 |
| **DD-01** 城市档案 | 读 | `city_playbook.lodging_areas`（`name`/`center`/`dining_density`/`night_transit_risk`）、`stations` | 区域打分候选、返程枢纽兜底 |
| **DD-02** 编排 | 读/写 state | 读 `bookings`/`candidate_cities`/`activities`/`timeline`(草稿)/`constraints`；写 `hotel_area`(LastValue)/`local_routes`(operator.add)/`dining` | 三节点入口 = 图节点函数 |
| **DD-03** 证据护栏 | 调用 | `enforce_provenance("route.minutes"/"route.distance_m"/"restaurant.open_hours"/"restaurant.phone", value, source_type)` | ETA/营业时间/电话定级，**禁绕过** |
| **DD-04** Provider | 调用 | `amap.call(Req(op="geocode"/"route"/"distance_matrix"/"poi_search", ...))` | 坐标补全、逐段耗时、区域粗估，**禁裸调** |

| **DD-09** 交通 | 读 state | `transport_options.candidates[*].door_to_door.{rail,air}.dest_station` | `resolve_return_hub` 无 booking 时的返程枢纽来源 |
| **DD-10** 回填 | 读 state | `bookings[*]`（`confirmed`/`kind`/`extracted.fields`：hotel/area/check_in、train/flight 的 from_station/dep_airport） | 已确认酒店 → `hotel_confirmed`；已确认返程 → 返程枢纽 |

| **DD-13** 组装 | 被读 | 渲染住宿区域卡 / 餐饮卡 / 市内路线，起入住/退房/餐厅营业提醒 | bundle 展示层 |

### 6.2 dining 与 DD-12 的迭代关系（草稿 → 精排）

`dining` 节点读 **DD-12 产出的时间线草稿**（`state["timeline"]` 首轮）来定饭点锚点（在哪个活动之后、几点、动线上哪个点附近），再回写 `dining`；DD-12 二轮据 `dining` 把餐厅作为途经点插入正式时间线。二者构成**一次单向草稿-精排**（非死循环）：

```mermaid
graph LR
    A[activities 选定] --> B[timeline 草稿]
    B --> C[dining 定锚点+召回]
    C --> D[timeline 正式排点插餐]
    D --> E[TripBundle]
```

> 若首轮无时间线草稿（探索期尚未排点），`plan_dining_anchors` 退化为**按活动开放时间的启发式**（午 12:00、晚 18:30、必要时下午茶），锚点 `near` 取活动/酒店坐标——仍产出可用候选，待 DD-12 排点后二轮精化。

```python
async def persist_local_products(db, plan_id: int,
                                 local_routes: list[dict], dining: list[dict]) -> None:

        for leg in sorted(local_routes, key=lambda x: x["seq"]):

                _wkt(leg["from_geo"]), _wkt(leg["to_geo"]),
                leg["mode"], leg["minutes"], leg["distance_m"],
                _jsonb({**leg["evidence"], "map_url": leg.get("map_url")}))

        await db.execute("DELETE FROM dining_picks WHERE plan_id = $1", plan_id)
        for group in dining:
            slot = group["meal_slot"]
            for c in group["candidates"]:
                await db.execute(
                    """INSERT INTO dining_picks
                       (plan_id, amap_poi_id, name, location, cuisine, price_band,
                        open_hours, phone, meal_slot, is_fallback, evidence)
                       VALUES ($1,$2,$3,
                               CASE WHEN $4 IS NULL THEN NULL ELSE ST_GeogFromText($4) END,
                               $5,$6,$7,$8,$9,$10,$11)""",
                    plan_id, c.get("amap_poi_id"), c["name"],
                    _wkt(c["location"]) if c.get("location") else None,
                    c.get("cuisine"), _jsonb(c.get("price_band")),
                    _fact_value(c.get("open_hours")), _fact_value(c.get("phone")),
                    slot, c.get("is_fallback", False),
                    _jsonb(_dining_evidence(c)))

def _wkt(geo: dict) -> str:
    return f"SRID=4326;POINT({geo['lng']} {geo['lat']})"

def _fact_value(fact: dict | None):
    """Fact 形态 {value, evidence} → 落库取 value（TEXT）；缺则 None。"""
    return fact.get("value") if isinstance(fact, dict) else fact

def _dining_evidence(c: dict) -> dict:
    """行级 evidence：合并候选整体来源 + open_hours/phone 分字段证据（供审计）。"""
    ev = dict(c.get("evidence") or {})
    if isinstance(c.get("open_hours"), dict):
        ev["open_hours"] = c["open_hours"].get("evidence")
    if isinstance(c.get("phone"), dict):
        ev["phone"] = c["phone"].get("evidence")
    ev["source"] = c.get("source", "amap")
    ev["rerank_score"] = c.get("rerank_score")
    return ev
```

## 7. 证据与状态

> 一切对外事实（ETA、营业时间、电话）**必须**经 DD-03 `enforce_provenance` 定级，本模块**不自定义**白名单，只按 DD-03 §5 `FIELD_SOURCE_POLICY` 消费。LLM 不得生成任何上述字段。

### 7.1 字段定级规则（对齐 DD-03 §5/§6）

| 产物字段 | `enforce_provenance` field | 允许来源 | 来源 → 状态映射 |
|---|---|---|---|
| `route_legs.minutes` / `.distance_m` | `route.minutes` / `route.distance_m` | `amap` / `rule` / `user_provided` | `amap`→`public_source_observed`；`rule`→`estimated`；`user_provided`→`confirmed_by_user` |
| `hotel_area.eta_to_activities` / `.eta_to_hub` | `route.minutes` | `amap` / `rule` | 同上（多段含 rule 则整体保守取 `estimated`，见 `_mode_src`） |
| `dining_picks.open_hours` | `restaurant.open_hours` | `amap` / `official_venue` / `user_provided` | `amap`→`public_source_observed`；无来源→`unknown` |
| `dining_picks.phone` | `restaurant.phone` | `amap` / `official_venue` / `user_provided` | 同上；缺→`unknown`（不编造） |
| `confirmed_hotel` | — | `user_provided`（DD-10） | `confirmed_by_user`；坐标由 geocode 补→该坐标 `public_source_observed` |
| `is_fallback` 稳妥备选 | `route.minutes`（其 ETA） | `rule` | `estimated`；`open_hours`/`phone` 多为 `unknown` |

### 7.2 状态语义（六态子集）

| 状态 | 出现场景 | 前端呈现 |
|---|---|---|
| `confirmed_by_user` | 用户回填的酒店/返程（DD-10） | ✅ 已确认，直接编入精确时间线 |
| `public_source_observed` | 高德 route/POI 的 ETA、营业时间、电话 | 「据高德」小字 + 可点 `map_url` 复核 |
| `estimated` | 直线/规则粗估 ETA（探索期或高德降级）、稳妥备选 | 「约」字样 + 「城市确定后精算」提示 |
| `unknown` | POI 无营业时间/电话 | 「营业时间以门店为准」，不显示编造值 |
| `expired` | 证据 TTL 过期（DD-03 判定） | 触发重取或降级标注 |

> **区域打分 `score` 不是对外事实**：仅用于排序，前端不展示为「事实」，只展示由 `_area_reasons` 生成的**自然语言理由**（模板拼装，非 LLM，输入均为已定级的 ETA/密度/风险）。

## 8. 降级设计

> 遵循 v1「优雅降级」与 DD-04「五件套」。任何外部依赖失败都**不阻断**流程，产出带 `estimated`/`unknown` 的可用结果 + `warnings`，并置 `degraded=True`。

| # | 触发场景 | 降级策略 | 证据影响 | 用户可见 |
|---|---|---|---|---|
| D1 | 高德 `route` 熔断/超额 | 该段用 `distance_matrix`；再失败用 `_straight_line_minutes` 直线估 | `amap`→`rule`（`estimated`） | 「约 X 分钟（估算）」+ `map_url` |
| D2 | 高德 `distance_matrix` 也不可用 | 全程直线估算（20km/h 经验车速） | 全段 `rule`/`estimated` | 提示「城市确定后精算」 |
| D3 | `poi_search`/`retrieve_dining` 空结果 | `build_fallback_pick`：区域连锁/酒店周边稳妥备选 | `is_fallback=True`，`estimated`/`unknown` | 「暂无精确匹配，给你一个稳妥备选」 |
| D4 | POI 无 `open_hours`/`phone` | 字段留空定 `unknown`，**不编造** | `unknown` | 「营业时间以门店为准」 |
| D5 | 城市档案无 `lodging_areas` | 以核心活动/枢纽中点生成 1 个「中间地带」兜底区域 | ETA 仍算/或估 | 单区域卡 + 说明 |
| D6 | 无返程 booking 且无 transport_options | `resolve_return_hub` 兜底取档案首个 rail 站 | `source=transport_options`（估） | 区域卡照常，返程枢纽标「预估」 |

```python
def build_fallback_pick(anchor: dict, hotel_area: dict) -> dict:
    """无 POI/检索空时的稳妥备选：锚定区域中心，标 is_fallback，ETA=estimated、营业时间=unknown。"""
    near = anchor.get("near") or (hotel_area.get("recommended_areas") or [{}])[0].get("center")
    oh = enforce_provenance("restaurant.open_hours", None, source_type=None)   # → unknown
    ph = enforce_provenance("restaurant.phone", None, source_type=None)         # → unknown
    return {
```

### 9.2 配额与成本

| 阶段 | 高德调用 | 量级（单次规划） | 控制手段 |
|---|---|---|---|
| 探索期区域打分 | `distance_matrix` | ≤ 区域数 × (活动数+1)，批量 | 缓存 7d + 直线降级 |
| 城市定后接驳 | `route` | ≈ 途经点数-1（逐段） | 缓存 7d；`map_url` 兜底不再调 |
| 酒店坐标补全 | `geocode` | ≤ 已确认酒店数 | 缓存 30d |
| 餐饮召回 | `poi_search`（经 DD-05） | 每饭点 1 次 | 缓存 3d + DD-05 复用向量库 |

> **成本铁律**：探索期**不**用 `route`（贵），只用 `distance_matrix`/直线；城市确定后才逐段精算。所有调用经 DD-04 `ResilientProvider`，命中缓存不计费。

## 10. 效果与验收标准

### 10.1 功能验收

| 项 | 验收标准 |
|---|---|
| 先区域后酒店 | `hotel` 输出 `recommended_areas`（区域卡）而非酒店列表；每卡含区域名 + ≥3 条理由 + 双向 ETA + 筛选清单 + ≥2 平台搜索入口；**不含**任何具体酒店预订链接 |
| 区域推荐合理性 | 打分 top1 应满足「到活动或枢纽 ETA 更优 / 餐饮密度更高 / 夜间风险更低」中至少两项；人工抽检 20 城命中率 ≥ 80% |
| 逐段接驳完整 | `local_routes` 覆盖「到达枢纽→酒店→各活动→各餐厅→返程枢纽」无断点；`seq` 连续；每段有 `minutes`/`distance_m`/`mode`/`evidence`/`map_url` |
| ETA 准确 | 城市定后 `route` 段 `source=amap`（`observed`）；探索期段可 `estimated`；抽检高德耗时与实际地图偏差 ≤ 20% |
| 动线餐饮非榜单 | 每饭点候选按 `distance_m`（动线契合）+ 偏好 + 忌讳重排；候选到 `anchor.near` 距离中位数 ≤ 1.2km；**恒有** 1 个 `is_fallback` |
| 证据合规 | 所有 `open_hours`/`phone`/`minutes` 均带 `evidence`；无来源字段为 `unknown`/`estimated`，无 LLM 编造 |
| BYO 接入 | 用户 BYO 链接候选正确 `source='byo'` 入池，完成坐标对齐与距离计算 |

## 12. 风险与缓解

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | 高德额度耗尽 / 熔断 | ETA 全走估算，精度下降 | 探索期只用 distance_matrix；缓存 7d；直线降级 + `map_url` 兜底；`degraded` 标注 |
| R2 | 城市档案 `lodging_areas` 缺失或粗糙 | 区域推荐质量差 | D5 中间地带兜底；档案质量纳入 DD-08 治理；抽检回流修档案 |
| R3 | POI 无营业时间/电话 | 餐饮信息不全 | 定 `unknown` 不编造；`official_venue` 补充；前端「以门店为准」 |
| R4 | 餐饮候选偏离动线（找餐馆不妥帖） | 复现竞品痛点 | `distance_m` 作 DD-05 重排强特征；锚点 `near` 取动线中心；验收距离中位 ≤1.2km |
| R5 | 时间线草稿缺失导致锚点不准 | 饭点时间/位置偏差 | 无草稿时启发式兜底；DD-12 二轮据 `dining` 精排回填 |
| R6 | 返程枢纽解析错误 | 区域打分方向偏 | 三级优先级（booking→transport_options→档案）；`source` 可审计；用户可 revise |
| R7 | BYO 链接无法解析坐标 | 收藏店无法入动线 | geocode 补坐标；失败标 `estimated` 并提示用户补充地址 |
| R8 | LLM 越权生成事实字段 | 违反证据优先 | 所有 open_hours/phone/minutes 强制经 `enforce_provenance`；代码评审禁绕过；单测 `test_no_llm_open_hours_when_missing` |
