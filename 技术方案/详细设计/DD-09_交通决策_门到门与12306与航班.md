# DD-09 交通决策（门到门 · 12306 策略卡 · 航班）· 详细设计

**详细设计系列 · 领域节点文档 · v1.0 · 2026 年 7 月**

> 本文定义 DD-02 图拓扑中的 **`transport` 节点**（TransportStrategy）的完整实现：**确定性门到门引擎**、**铁路查询策略卡 + 12306 起售时间 + 官方深链**、**航班多机场比较与门到门对比**、**三类默认方案（时间优先/稳妥优先/均衡）**、**无票策略**，并产出下游消费的 `transport_options`（含门到门比较、策略卡、`prefill` 预填清单、`presale` 起售提醒）。
>
> **上游依据**：v1 §9.1（门到门）、§9.2（12306 策略卡 + 起售时间 + 深链）、§2.1/§2.2（数据可行性）；DD-01（`city_playbook.stations` 提供车站/机场，本节点产出进 `state`、不写业务表）；DD-02 §5（节点契约：读 `constraints`/`candidate_cities`，写 `transport_options`；受 Guard）；DD-03 §5/§6（`FIELD_SOURCE_POLICY` 与闸三禁编）；DD-04（VariFlight 只取时刻、不取实时价；高德门到门；禁止裸调）；PRD 5.4/5.5/6.2。
> **下游消费者**：DD-02（`await_booking` interrupt payload 消费 `prefill`/`presale`）、DD-10（回填确认实际车次/航班后回写 `bookings`）、DD-13（起售提醒排程）、前端交通比较卡。
> **三条硬约束落地**：① **不做交易**（12306 无 API、不抓余票、不代购；只出策略卡 + 官方深链 + 起售提醒 + 回填）；② **证据优先**（缓冲=`estimated`；**票价/余票禁止 LLM 生成**，受 DD-03 闸三约束）；③ **轻后端重证据**（门到门是可解释确定性计算，不靠模型感觉）。

## 2. 设计目标与非目标

**目标**：
1. **门到门决策**（核心差异化）：算接驳 + 缓冲 + 运行时间 + 有效游玩，**不只比票面时长**；每段带 `source`（`amap`/`rule`/`variflight`）。
2. **诚实取舍**：12306 查询页防护强，**不承诺参数式一键直达某车次**，改为**官方入口 + 预填清单**；起售时间是**规则计算**（预售期 15 天），标注「以 12306 当前页面为准」。
3. **禁编红线**：`transport_options` 内**不出现任何 LLM 生成的票价/余票**；席别价格、实时余票一律留占位「待你在官方平台确认」，交 DD-03 闸三 CI 断言兜底。
4. **可降级**：无航班数据 → 机场对比 + 时段建议；地图额度受限 → 缓存 + 直线估算 + 地图链接；交通未确认 → 只出时间窗，不出伪精确日程。
5. **确定性、可单测**：所有算法为纯函数 + 注入 Provider，mock 掉 `constraints`/`candidate_cities`/Provider 即可独立测试。

**非目标**：
- ❌ 不做实时余票查询/刷票/候补下单（12306 无 API，且违背「不做交易」）。
- ❌ 不做机票实时比价爬取（比价交用户信任入口，不碰账户）。
- ❌ 不让 LLM 决定交通方式或生成时刻/票价（方式判断是规则；时刻来自静态时刻表回填/VariFlight）。
- ❌ 不在本节点写业务表或做时间线排程。

## 5. 核心算法（可运行级代码）

> 时区统一 `Asia/Shanghai`；所有缓冲/规则耗时标 `estimated`；所有 route 段经 DD-03 `enforce_provenance("route.minutes", ...)`；**无任何票价/余票生成**。

### 5.0 公共依赖与 DTO

```python
from __future__ import annotations
import asyncio, math
from dataclasses import dataclass, field, asdict
from datetime import date, datetime, time, timedelta
from zoneinfo import ZoneInfo
from typing import Literal

# DD-03 复用（证据定级唯一入口，禁止绕过）
from dd03_guard import enforce_provenance, Evidence, VerificationStatus
# DD-04 复用
from dd04_provider import Req, ResilientProvider

CN_TZ = ZoneInfo("Asia/Shanghai")

@dataclass
class Leg:
    seg: str            # to_hub|buffer_in|run|buffer_out|to_first
    label: str
    minutes: int
    source: str         # amap | rule | variflight
    note: str = ""
    def evidence(self) -> Evidence:
        # route 段与缓冲段统一经 DD-03 闸一定级：amap→observed，rule→estimated
        field_name = "route.minutes"
        fact = enforce_provenance(field_name, self.minutes, self.source)
        return fact.evidence

@dataclass
class DoorToDoor:
    mode: str
    station: str
    dest_station: str
    legs: list[Leg]
    total_minutes: int
    face_minutes: int
    depart_at: datetime | None
    arrive_at: datetime | None
    effective_play_minutes: int

    def to_dict(self) -> dict:
        return {
            "mode": self.mode, "station": self.station, "dest_station": self.dest_station,
            "legs": [asdict(l) for l in self.legs],
            "total_minutes": self.total_minutes, "face_minutes": self.face_minutes,
            "depart_at": self.depart_at.isoformat() if self.depart_at else None,
            "arrive_at": self.arrive_at.isoformat() if self.arrive_at else None,
            "effective_play_minutes": self.effective_play_minutes,
            "evidence_by_seg": {l.seg: self.legs_evidence(l) for l in self.legs},
        }
    @staticmethod
    def legs_evidence(l: Leg) -> dict:
        ev = l.evidence()
        return {"source_type": ev.source_type, "verification_status": ev.verification_status}
```

### 5.2 高德接驳耗时（走 DD-04，禁止裸调；失败降级直线估算）

```python
async def _amap_minutes(deps: TransportDeps, frm: dict, to: dict,
                        mode: str = "transit") -> tuple[int, str, str]:
    """返回 (minutes, source, note)。source ∈ {'amap','rule'}（降级=rule 直线估算）。"""
    req = Req(op="route",
              params={"origin": f"{frm['lng']},{frm['lat']}",
                      "destination": f"{to['lng']},{to['lat']}", "mode": mode},
              cache_ttl=7 * 86400)      # 路线 7 天缓存（DD-04 §4.1）
    r = await deps.amap.call(req)
    if r.ok and r.data and r.data.get("duration_minutes") is not None:
        return int(r.data["duration_minutes"]), "amap", ("降级路径" if r.degraded else "公交/驾车")
    # 降级：Haversine 直线距离 / 经验车速（城市 25km/h），标 rule/estimated + 附地图链接
    return _straight_line_minutes(frm, to), "rule", "地图额度受限→直线估算"

def _straight_line_minutes(frm: dict, to: dict, kmph: float = 25.0) -> int:
    R = 6371.0
    dlat = math.radians(to["lat"] - frm["lat"]); dlng = math.radians(to["lng"] - frm["lng"])
    a = (math.sin(dlat / 2) ** 2
         + math.cos(math.radians(frm["lat"])) * math.cos(math.radians(to["lat"]))
         * math.sin(dlng / 2) ** 2)
    km = 2 * R * math.asin(math.sqrt(a))
    return max(10, round(km / kmph * 60))
```

### 5.3 铁路/航班运行时间（时刻来自静态时刻表回填 / VariFlight，绝不 LLM 生成）

```python
class RailRuntimeProvider:
    """铁路运行时间：静态时刻表（运营维护）或用户回填；无数据→None(待回填)。
    绝不调用 LLM，绝不返回票价/余票。"""
    def runtime_minutes(self, from_station: str, to_station: str,
                        depart_at: datetime) -> tuple[int | None, str]:
        row = self._lookup(from_station, to_station)   # DB/YAML 静态时刻
        if row is None:
            return None, "unknown"     # 无静态时刻→门到门 run 段待回填
        return int(row["typical_minutes"]), "rule"     # 静态时刻属规则近似→estimated

async def _flight_runtime(deps: TransportDeps, dep_ap: str, arr_ap: str,
                          depart_at: datetime) -> tuple[int | None, str, dict | None]:
    """VariFlight flight_schedule：只取时刻/机型/准点率，绝不取实时价（DD-04 §5 强约束）。"""
    req = Req(op="flight_schedule",
              params={"dep": dep_ap, "arr": arr_ap, "date": depart_at.date().isoformat()},
              cache_ttl=12 * 3600)     # 时刻 12h 缓存
    r = await deps.variflight.call(req)
    if not (r.ok and r.data and r.data.get("flights")):
        return None, "unknown", None   # 无航班数据→降级到机场对比+时段建议（§8）
    f = min(r.data["flights"], key=lambda x: x["duration_minutes"])  # 取最短时刻代表
    return int(f["duration_minutes"]), "variflight", f
```

### 5.4 门到门引擎 + 有效游玩时间

```python
def compute_effective_play_time(arrive_at: datetime | None,
                                day_play_end: datetime | None,
                                min_meaningful: int = 90) -> int:
    """有效游玩时间 = 到达时刻到当日游玩截止的可用分钟；不足 min_meaningful 记 0（不值当）。"""
    if arrive_at is None or day_play_end is None:
        return 0
    minutes = int((day_play_end - arrive_at).total_seconds() // 60)
    return minutes if minutes >= min_meaningful else max(0, minutes) * (minutes >= 0)

async def door_to_door(deps: TransportDeps, origin_geo: dict, dest_city: dict,
                       mode: str, depart_at: datetime, *,
                       with_checked_bag: bool = True,
                       day_play_end: datetime | None = None) -> DoorToDoor:
    stations = dest_city.get("playbook", {}).get("stations", [])
    if mode == "rail":
        hub = _nearest_station(origin_geo, dest_city["origin_stations"], "rail")
        dst = _nearest_station(dest_city["core_geo"], stations, "rail")
        ingress, egress = rail_buffers()
        m_to_hub, s1, n1 = await _amap_minutes(deps, origin_geo, hub["location"])
        run, src_run = deps.rail_runtime.runtime_minutes(hub["name"], dst["name"], depart_at)
        run = run if run is not None else 0        # None→0 并附待回填 warning（调用方处理）
        m_to_first, s2, n2 = await _amap_minutes(deps, dst["location"], dest_city["core_geo"])
        legs = [
            Leg("to_hub", f"出发地→{hub['name']}", m_to_hub, s1, n1),
            Leg("buffer_in", "进站+安检缓冲", ingress, "rule", "规则常量"),
            Leg("run", f"{hub['name']}→{dst['name']}(运行)", run, "rule", src_run),
            Leg("buffer_out", "出站", egress, "rule", "规则常量"),
            Leg("to_first", f"{dst['name']}→首个活动/酒店", m_to_first, s2, n2),
        ]
        station_name, dest_station_name = hub["name"], dst["name"]
    elif mode == "air":
        hub = _nearest_station(origin_geo, dest_city["origin_stations"], "air")
        dst = _nearest_station(dest_city["core_geo"], stations, "air")
        ci, eg = air_buffers(with_checked_bag)
        m_to_hub, s1, n1 = await _amap_minutes(deps, origin_geo, hub["location"], mode="drive")
        run, src_run, _f = await _flight_runtime(deps, hub["iata"], dst["iata"], depart_at)
        run = run if run is not None else 0
        m_to_first, s2, n2 = await _amap_minutes(deps, dst["location"], dest_city["core_geo"], mode="drive")
        legs = [
            Leg("to_hub", f"出发地→{hub['name']}", m_to_hub, s1, n1),
            Leg("buffer_in", "值机+安检+登机缓冲", ci, "rule", "规则常量"),
            Leg("run", f"{hub['name']}→{dst['name']}(飞行)", run, "variflight" if run else "rule", src_run),
            Leg("buffer_out", "下机+取行李" if with_checked_bag else "下机", eg, "rule", "规则常量"),
            Leg("to_first", f"{dst['name']}→首个活动/酒店", m_to_first, s2, n2),
        ]
        station_name, dest_station_name = hub["name"], dst["name"]
    else:
        raise ValueError(f"unsupported mode: {mode}")

    total = sum(l.minutes for l in legs)
    face = next((l.minutes for l in legs if l.seg == "run"), 0)
    arrive_at = depart_at + timedelta(minutes=total) if total else None
    play = compute_effective_play_time(arrive_at, day_play_end)
    return DoorToDoor(mode=mode, station=station_name, dest_station=dest_station_name,
                      legs=legs, total_minutes=total, face_minutes=face,
                      depart_at=depart_at, arrive_at=arrive_at, effective_play_minutes=play)

def _nearest_station(geo: dict, stations: list[dict], stype: str) -> dict:
    cands = [s for s in stations if s.get("type") == stype] or stations
    return min(cands, key=lambda s: _straight_line_minutes(geo, s["location"]))
```

### 5.5 交通方式判断 + 三类默认方案（PRD 6.2）

```python
def decide_mode(distance_km: float, constraints: dict) -> tuple[str, str]:
    """规则判断交通方式（绝非 LLM）。返回 (verdict, reason)。"""
    accept_flight = constraints.get("accept_flight", True)
    accept_night = constraints.get("accept_night_train", False)
    if distance_km < 450:
        return "high_speed_first", "距离较近，高铁门到门通常优于飞机"
    if distance_km > 1400:
        return ("air_first" if accept_flight else "sleeper_option"), \
               ("距离远，飞机门到门更省时" if accept_flight else "距离远且不接受飞机，建议卧铺过夜")
    # 中等距离：两者都值得比较；夜间列车可提高有效游玩
    v = "compare"
    r = "距离适中，高铁与飞机门到门接近，建议都比较"
    if accept_night:
        r += "；可考虑夜间卧铺提高有效游玩时间"
    return v, r

def build_transport_plans(d2d_rail: DoorToDoor | None, d2d_air: DoorToDoor | None,
                          constraints: dict) -> list[dict]:
    """三类默认方案：时间优先 / 稳妥优先 / 均衡（对应 PRD 交通比较卡）。"""
    cands = [d for d in (d2d_rail, d2d_air) if d and d.total_minutes > 0]
    if not cands:
        return []
    plans = []
    # 时间优先：门到门总耗时最短
    fastest = min(cands, key=lambda d: d.total_minutes)
    plans.append(_plan("time_first", "时间优先", fastest,
                        "门到门总耗时最短，牺牲部分缓冲冗余"))
    # 稳妥优先：留足缓冲的方式（优先高铁：受天气/流程影响小）
    robust = d2d_rail or fastest
    plans.append(_plan("robust", "稳妥优先", robust,
                        "缓冲冗余大、受天气/流程影响小，适合赶行程/带老人小孩"))
    # 均衡：有效游玩时间最高
    balanced = max(cands, key=lambda d: d.effective_play_minutes)
    plans.append(_plan("balanced", "均衡", balanced,
                        "综合耗时与有效游玩时间的折中"))
    return plans

def _plan(kind: str, label: str, d2d: DoorToDoor, why: str) -> dict:
    return {
        "kind": kind, "label": label, "mode": d2d.mode,
        "door_to_door_minutes": d2d.total_minutes,
        "face_minutes": d2d.face_minutes,
        "effective_play_minutes": d2d.effective_play_minutes,
        "why": why,
        "price": None,           # 票价禁编：留占位，待用户官方平台确认
        "price_note": "票价请在官方平台确认（本产品不生成票价）",
    }
```

```python
def transport_strategy(state: "TripPlanState", deps: TransportDeps) -> dict:

    origin_city = constraints["origins"][0].split("·")[0] if constraints.get("origins") else ""

        dist_km = _straight_line_minutes(origin_geo, city["core_geo"]) / 60 * 25
        verdict, reason = decide_mode(dist_km, constraints)
        out_at = _parse_dt(constraints["earliest_depart"])
        day_end = _parse_dt(constraints.get("play_end", constraints["earliest_depart"]))
        d2d_rail = await door_to_door(deps, origin_geo, city, "rail", out_at, day_play_end=day_end)
        d2d_air = None

                                         with_checked_bag=False, day_play_end=day_end)

        if d2d_rail.legs[2].minutes == 0:               # run 段待回填
            warnings.append(f"{city['city']}：铁路运行时间待回填，门到门为下限估计")

        travel_dates = _weekend_dates(out_at)
        windows = {"verdict": verdict, "out_window": "周六早 06:00–08:00",
                   "station_open_time": "08:00", "depart_at": out_at,

                   "train_suggestions": [], "suggest_windows": ["周五 19:30–22:30 起飞",
                                                                 "周六 06:30–08:00 起飞"]}
        rail_card = build_rail_strategy_card(
            origin_city, city["city"], windows, city["playbook"]["stations"], travel_dates)
        flight_card = await build_flight_strategy_card(deps, {"name": origin_city,
                        "stations": city["origin_stations"]}, city, windows)
        presale_all.extend([{**p, "city": city["city"]} for p in rail_card["presale"]])

                "recommended_mode": verdict, "reason": reason,

              "window_suggestions": fs.get("suggest_windows", []),
```

| **DD-02** | 读写 | 读 `constraints`/`candidate_cities`；写 `transport_options`/`warnings` | 图边 `research → transport → await_booking`；`transport_options` 为 dict（LastValue，本节点单一 owner）。 |
| **DD-02** | 消费 | `await_booking` interrupt payload | `build_prefill_hints(state["transport_options"])` → `prefill`；`state["transport_options"]["presale"]` → `presale_reminders`（见 DD-02 §6.1/§6.2，逐字对齐）。 |
| **DD-04** | 调用 | 高德 `route`/`distance_matrix`；VariFlight `flight_schedule` | 经 `ResilientProvider`（缓存/限流/熔断/降级），**禁止裸调**；VariFlight **只取时刻不取实时价**（DD-04 §5 强约束）。 |
| **DD-03** | 校验 | `enforce_provenance` / 闸三 | 每段 route/缓冲经闸一定级（amap→observed，rule→estimated）；`train.*`/`flight.*` 票价余票**禁编**，交闸三 CI 断言。 |
| **DD-10** | 下游 | 回填确认实际车次/航班 | 用户在 `await_booking` 中断期回填 → DD-10 抽取+逐字段确认 → resume 注入 `bookings`（`confirmed_by_user`）；确认后的实际 `run` 时间**回填**替换 door_to_door 的估算 run 段（重规划从 `transport` 或 `timeline` 重入）。 |
| **DD-13** | 下游 | 起售提醒排程 | 消费 `transport_options["presale"][*].open_at` 生成 `reminders(type='presale')`（DD-01 §8.7）；ICS/Web Push 投递（v1 §9.7）。 |
| **DD-12** | 下游 | 门到门耗时/返程缓冲 | `timeline` 用确认后的 `bookings` 精确时刻 + 本节点缓冲常量做返程缓冲校验（`RETURN_TIGHT` 走 DD-02 条件边回 `transport`）。 |

**回填替换 run 段（DD-10 → 本节点重算）示意**：

```python
def refresh_door_to_door_with_booking(d2d: dict, booking: dict) -> dict:
    """DD-10 确认车次/航班后，用实际发到时刻替换 run 段（confirmed_by_user）。"""
    actual = int(booking["extracted"]["run_minutes"])       # 来自用户确认，非 LLM
    for leg in d2d["legs"]:
        if leg["seg"] == "run":
            leg["minutes"] = actual; leg["source"] = "user"; leg["note"] = "用户回填确认"
    d2d["total_minutes"] = sum(l["minutes"] for l in d2d["legs"])
    d2d["face_minutes"] = actual
    return d2d
```

## 7. 证据与状态（缓冲=estimated；票价/余票禁编）

**定级规则（全部经 DD-03，不得绕过 `enforce_provenance`）**：

| 字段/段 | source_type | verification_status | 说明 |
|---|---|---|---|
| 接驳段 `to_hub`/`to_first`（高德成功） | `amap` | `public_source_observed` | 高德路线耗时；`route.minutes` 白名单允许。 |
| 接驳段（高德降级直线估算） | `rule` | `estimated` | 额度受限降级，标「直线估算」。 |
| 缓冲段 `buffer_in`/`buffer_out` | `rule` | `estimated` | **门到门缓冲=估算**（§5.1 常量表）。 |
| 铁路 `run`（静态时刻） | `rule` | `estimated` | 静态时刻近似；确认后由回填替换为 `confirmed_by_user`。 |
| 航班 `run`/时刻 | `variflight` | `public_source_observed` | VariFlight 时刻，标「待确认」；**不含票价**。 |
| 起售时间 `presale.open_at` | `rule` | `estimated` | 规则计算，标「以 12306 当前页面为准」。 |
| **票价 `train.price`/`flight.price`** | — | **禁生成** | 一律 `None` + 占位「待你在官方平台确认」。 |
| **余票 `train.availability`** | — | **禁生成** | 不查、不估、不显示；无票走 `no_ticket_strategy`。 |

**闸三对接（DD-03 §6，进 CI）**：`transport_options` 内任何 `train.*`/`flight.*`/`*.availability` 字段若 `source_type=='llm'`，在 DD-13 `compose` 出稿前 `assert_no_fabricated_transport` **必抛错**。本节点从**源头**保证：票价字段恒为 `None`、时刻仅来自 `rule`/`variflight`/`user`，**从不写 `source_type='llm'` 的交通事实**。

```python
# 本节点内不变量（可写成 CI 断言）：transport_options 中不得出现 LLM 生成的交通事实
def assert_transport_no_llm(transport_options: dict) -> None:
    for cand in transport_options.get("candidates", []):
        for p in cand.get("plans", []):
            assert p.get("price") is None, "票价禁编：plan.price 必须为 None"
        for d in cand.get("door_to_door", {}).values():
            if not d:
                continue
            for st in d.get("evidence_by_seg", {}).values():
                assert st["source_type"] != "llm", "交通段来源不得为 llm"
        for s in cand.get("flight_strategy", {}).get("schedules", []):
            assert "price" not in s, "航班时刻卡不得含票价"
```

## 8. 降级设计

| 场景 | 降级行为 | 标注 |
|---|---|---|
| **无航班时刻数据**（VariFlight 无结果/熔断） | 航班退化为**机场对比清单 + 时段建议**（`flight_strategy.degraded=true`），仍给门到门下限估计与 checklist | `warnings` 追加；`degraded=true` |
| **地图额度受限/超时** | 接驳段走**直线估算**（`rule`/`estimated`）+ 生成一键地图链接；`ResilientProvider` 已返回 `degraded=True` | 段 `note="地图额度受限→直线估算"` |
| **铁路运行时间缺失**（无静态时刻/未回填） | `run=0` 作下限，门到门标「待回填」，只出**时间窗**不出伪精确日程 | `warnings` 追加「运行时间待回填」 |
| **交通未确认**（尚未回填） | `await_booking` 前只产出**时间窗 + 策略卡 + 门到门对比**，**不生成确认版逐小时日程**（v1 §10 / PRD 09 韧性） | 探索版 bundle |
| **跨城均不成立**（门到门过长、有效游玩≈0） | 由 DD-08 回退近郊/同城候选；本节点对每候选城标 `effective_play_minutes` 供上游取舍 | `warnings` |

> **总原则**：任何单点失效，用户仍拿到有用输出——最差是「机场/车站对比 + 时段建议 + 官方入口 + 待确认标注」，绝不空结果、绝不编造。

## 9. 配置与配额

**缓冲常量（`§5.1 BUFFER_RULES_MIN`，可运营配置）**：以 YAML 维护，支持按城市/车站覆盖（如大兴机场 egress 偏大）；变更走配置发布，**永远标 `estimated`**，不冒充官方。

```yaml
# config/transport_buffers.yaml
rail:   {ingress: 25, egress: 15}
air:    {checkin_with_bag: 90, checkin_no_bag: 60, egress_with_bag: 35, egress_no_bag: 20}
overrides:
  "北京大兴国际机场": {egress_with_bag: 45}   # 大兴取行李+出机场偏久
presale_days: 15
straight_line_kmph: 25       # 直线估算经验车速
```

**配额与成本（对齐 DD-04 §4/§8、v1 §11）**：

| Provider/op | 本节点用量特征 | 控成手段 |
|---|---|---|
| 高德 `route`（接驳段） | 每候选城 × 每方式 ≥2 段（to_hub/to_first） | 7 天缓存；探索期用直线估算/距离矩阵；命中缓存优先 |
| VariFlight `flight_schedule` | 每候选城机场组合（虹桥/浦东×首都/大兴=4 组） | **12h 缓存**；只取时刻不取价（更便宜）；候选城 top-N 限制；日配额上限接近即降级到机场对比 |
| 铁路运行时间 | 本地静态时刻表/DB | 无外呼成本；运营维护 |

> **成本红线**：VariFlight 为商用付费，机场组合数会放大调用；用 `distance_matrix` 先粗筛机场，仅对 top 组合取时刻；日成本上限触顶 → 降级机场对比（§8）。

## 10. 效果与验收标准（DoD）

**功能验收**：
1. **门到门 vs 票面对比正确**：给定「飞行票面 2.2h / 高铁 4.5h」样例，门到门计算后飞机总耗时（含 90min 值机 + 两端接驳 + 取行李）应与高铁接近，输出的 `total_minutes`/`effective_play_minutes` 与手算一致（单测断言，误差 0）。
2. **起售时间计算准确**：`presale_open_time(乘车日=周六, "08:00")` = 乘车日 -14 天当天 08:00（含时区 `Asia/Shanghai`）；跨月/跨闰边界正确（参数化单测）。
3. **无编造票价（CI 红线）**：构造含 `source_type='llm'` 的交通字段输入，`assert_transport_no_llm` 与 DD-03 `assert_no_fabricated_transport` **必抛错**；正常产出中 `plan.price` 恒为 `None`、无 `availability` 字段。
4. **三方案齐全**：`plans` 含 `time_first`/`robust`/`balanced` 三类，各带门到门耗时、有效游玩、理由。
5. **无票策略**：`no_ticket_strategy.options` 含候补/前后车次/同城异站/卧铺/改飞/改目的地/调整长度七项。
6. **降级**：mock VariFlight 空结果 → `flight_strategy.degraded=true` + `warnings`；mock 高德超时 → 接驳段 `source='rule'`/`estimated`。
7. **契约对接**：`build_prefill_hints(transport_options)` 返回 `{'rail':{...},'flight':{...}}`；`transport_options['presale']` 为可被 DD-13 排程的列表（每项含 `open_at`）。

**测试用例（pytest；Provider 用 stub，`clock` 注入固定时钟）**：

```python
def test_door_to_door_air_vs_rail_fair_compare(deps_stub):
    # 高铁票面 268min，飞机票面 132min；门到门后飞机因缓冲接近高铁
    rail = asyncio.run(door_to_door(deps_stub, ORIGIN, DEST, "rail", DEPART))
    air  = asyncio.run(door_to_door(deps_stub, ORIGIN, DEST, "air",  DEPART, with_checked_bag=False))
    assert rail.face_minutes == 268 and air.face_minutes == 132
    # 门到门差距远小于票面差距（核心差异化断言）
    assert abs(rail.total_minutes - air.total_minutes) < (268 - 132)

def test_presale_open_time():
    # PRESALE_DAYS=15 含当天 → 起售 = 乘车日 -14 天
    assert presale_open_time(date(2026, 7, 25), "08:00") == \
        datetime(2026, 7, 11, 8, 0, tzinfo=CN_TZ)

def test_no_fabricated_price(transport_options):
    assert_transport_no_llm(transport_options)     # 不抛错
    for c in transport_options["candidates"]:
        for p in c["plans"]:
            assert p["price"] is None
```

> 注：`PRESALE_DAYS=15` 含当天，起售日 = 乘车日 -(15-1) = 乘车日 -14 天（如乘车 7/25 → 起售 7/11）。测试基准以此为准，站点具体时点由运营维护。

## 12. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| VariFlight 成本随机场组合放大 | 中 | `distance_matrix` 先粗筛，仅 top 组合取时刻；12h 缓存；日上限触顶降级机场对比 |
| 缓冲常量与真实排队偏差大 | 中（门到门失真） | 常量可按城市/车站 override；结合 `station.access_note`；永远标 `estimated`，用户可修正 |
| 铁路静态时刻表维护滞后 | 中 | 缺失即标「待回填」，只出时间窗；确认后回填替换 run 段（`confirmed_by_user`） |
| 12306 参数式深链失效 | 低 | 已采「官方入口 + 预填清单」诚实取舍，不依赖参数直达 |
| 起售规则/各站时点变化 | 低 | `PRESALE_DAYS` 与站点时点配置化；文案统一标「以 12306 当前页面为准」 |
| 开发误把票价/余票写进产出 | 高（可信 KPI） | 源头恒 `None` + `assert_transport_no_llm` + DD-03 闸三 CI 断言双保险 |
| 多候选城并发调用超配额 | 中 | 候选城 top-N 限制；`ResilientProvider` 令牌桶 + 熔断；`asyncio.gather` 并发受限 |
