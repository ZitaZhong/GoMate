# DD-06 活动情报流水线 · 详细设计

**详细设计系列 · 领域模块文档 · v1.0 · 2026 年 7 月**

> 本文定义「周末去哪儿」的**异步情报生产流**：把散落在官方场馆/文旅日历/开放数据上的"当周活动"，抓取→清洗→抽取→归一→去重→定级→向量入库，沉淀为带证据的 `activities` 资产，供检索（DD-05）与规划（DD-02）**只读**消费。它是 v1 §8 的落地，也是产品"当周活动驱动、不做静态热门排列组合"这一差异化的**数据地基**。
>
> **上游依据**：v1 §8（情报流水线）、§3.5（抓取抽取决策）、§10（韧性）、v1.1 增补 E④（复用 `gpt-researcher` 找官方入口 / 事实定级走自有管线）、DD-01（`source_registry`/`raw_pages`/`activities`/`venues` 表与枚举，DD-06 是这三张表的**唯一写入方**）、DD-03（`Fact/Evidence`、`enforce_provenance`、六态定级）、DD-04（httpx/Playwright/清洗/PydanticAI 抽取/高德地理编码/embedding，禁止裸调外部 API）、DD-05（入库调 `svc.embed` 生成 `embedding`、写 `embedding_version`）、PRD 05（活动情报系统、来源可信度七级）。
> **下游消费者**：DD-05（检索，只读 `activities`）、DD-08（目的地发现/活动研究，经 DD-05 检索间接消费）、DD-02 `research` 节点（检索空时触发本模块补搜）、运营/人工审核台。
> **一句话**：**只抓官方公开页、遵 robots 与双层限速；每个对外事实带 `evidence_quote` 回锚原文；官方源→`official_source_confirmed`，搜索未核实→`unknown`；事实抽取与定级绝不走 `gpt-researcher` 的报告，只走本模块自有证据管线。**

## 1. 模块职责与边界

| 项 | 说明 |
|---|---|
| **职责** | 提供**异步情报生产流**：来源注册 → 调度 → 抓取 → 清洗 → LLM 抽取 → 归一 → 去重&实体对齐 → `enforce_provenance` 定级 → embed 入库 → 过期清理 → 人工审核台。产出唯一资产 = 带证据的 `activities` 行。 |
| **边界内** | Celery 调度与任务、Fetcher（httpx/Playwright + robots + ETag + 双层限速）、正文清洗、`emit_activity` 抽取工具与 schema、归一（时间/城市/场馆/坐标）、`fingerprint` 一级去重、pgvector 二级实体对齐、定级接线、embed 入库、`expires_at` 过期、审核队列、合规红线代码。 |
| **边界外** | 检索算法与召回/重排（DD-05）；活动打分与城市推荐（DD-08）；证据类型与定级规则本身（DD-03 定义，本模块只**调用**）；外部 Provider 五件套（DD-04）；表结构（DD-01 定义，本模块只**写入**）。 |
| **架构位置** | v1 §4.1 分层图"数据智能层 · 活动情报流水线"；v1 §4.2「异步情报生产流，与规划请求彻底解耦」。它**不是** DD-02 的图节点，而是独立跑在 Celery Worker 上的后台流水线，与规划流通过 `activities` 表**读写解耦**（DD-01 §13 归属矩阵铁律）。 |

```text

        ▲                                                      │
```

## 2. 设计目标与非目标

**目标**：
1. **证据优先**：每个对外事实字段（`start_at`/`price_text`/`booking_url`）都带 `evidence_quote`（原文引用）回锚，抽取后**校验引用确实出现在清洗正文里**，从工程上堵死 LLM 编造。
2. **合规内建**：robots 校验、双层令牌桶限速、真实 UA + 联系邮箱、ETag 条件请求、只抓官方公开页——写进代码，不靠自觉（v1 §8.3）。
3. **定级正确**：官方源→`official_source_confirmed`，开放数据→`public_source_observed`，搜索未回官方核实→`unknown`，全部经 DD-03 `enforce_provenance`（不自造 `confirmed`）。
4. **去重准**：`fingerprint` 一级（规则）+ pgvector 二级（语义近邻）合并同一活动的多来源，**保留最高可信来源为主记录**。
5. **可运营**：来源注册表可增删；抽取失败/来源冲突进人工审核台；过期自动下架。
6. **低成本克制**：低频调度、ETag 免重抓、内容无变化不重抽、抽取走小模型（`activity_extract`=qwen-turbo）。

**非目标**：
- ❌ 规划节点不自己裸抓（交本模块）；批量预热为主。⚠️ v2 调整：本模块新增同步入口 `ingest_realtime`，供 **DD-17 实时深研按需实时入库**（同抓取/抽取/定级/去重管线，见本文 v2 增补）；DD-02 `research` 仍不裸抓（调 DD-17）。
- ❌ 不把 `gpt-researcher` 的调研报告当事实——它**只用于"找官方入口 URL"**，事实抽取与定级一律回本模块管线（v1.1 E④ 铁律）。
- ❌ 不抓登录后内容、交易平台余票/实时价、个人数据。
- ❌ 不做检索/打分（DD-05/DD-08 的活）。
- ❌ 不新造证据类型或定级规则（DD-03 的活）。

## 3. 数据模型（严格引用 DD-01，不另立）

本模块**只写** DD-01 §7 定义的四张表，字段一律以 DD-01 为准，下表标注本模块的读写角色与关键用法。

### 3.1 复用 DD-01 既有表

| 表 | DD-06 角色 | 关键字段用法 |
|---|---|---|
| `source_registry`（DD-01 §7.3） | **唯一写入方**（运营/审核台也经本模块 API 写） | 调度读 `enabled/fetch_interval/last_fetched_at`；抓取读 `entry_url/parser_kind/robots_ok`；`trust_level`(1~7) 映射 PRD 来源分级；写 `last_fetched_at` |
| `raw_pages`（DD-01 §7.4） | **唯一写入方** | `content_hash` 判正文是否变化（无变化不重抽）；`etag` 存条件请求校验值；`clean_md` 存清洗后正文（抽取输入）；`http_status` 记抓取结果 |
| `venues`（DD-01 §7.2） | 写入（活动的空间锚点，缺则 upsert） | `UNIQUE(city_code, name)` 幂等 upsert；`location` 由高德地理编码回填；`official_url` 记官方页 |
| `activities`（DD-01 §7.5） | **唯一写入方** | `fingerprint`(UNIQUE) 一级去重键；`evidence`(JSONB) 定级结果；`verification_status`；`embedding`+`embedding_version`（DD-05 `svc.embed`）；`expires_at` 过期下架；`availability_status` 默认 `user_must_confirm` |

> `activities` 的 `search_tsv` 是 DB 端 `GENERATED ALWAYS AS ... STORED`（DD-01 §7.5），**本模块不写该列**；`embedding` 由本模块入库时显式写入（DD-05 §8）。

**`activities.evidence` 落库结构**（DD-01 §5 / DD-03 §3，本模块产出后写入）：

```jsonc
{
  "source_type": "official_venue",                    // DD-01 source_type 枚举
  "source_url":  "https://www.chnmuseum.cn/...",       // 官方页 URL（raw_pages.url）
  "fetched_at":  "2026-07-18T10:00:00Z",               // = raw_pages.fetched_at
  "verification_status": "official_source_confirmed",  // 六态，由 enforce_provenance 定
  "confidence":  0.92,
  "note":        "解析自官方展览页；evidence_quote 已回锚"
}
```

### 3.2 需回改 DD-01 的新增项（明确标注）

DD-01 §7.5 与 v1 §8 提到"人工审核台（编辑复核/纠错/加白）"与"多来源冲突记录以便人工审核"，但**未定义审核队列表**。为落地 §5.9 审核台与 §3.1 冲突记录，本模块需新增下列结构，**须回改 DD-01 并通知下游**（在 DD-01 补进后本文引用即可）：

```sql
-- 【需回改 DD-01】活动抽取/去重异常与冲突的人工审核队列（DD-06 写，运营读写）
CREATE TABLE activity_review_queue (
  id            BIGSERIAL PRIMARY KEY,
  raw_page_id   BIGINT REFERENCES raw_pages(id) ON DELETE CASCADE,
  source_id     BIGINT REFERENCES source_registry(id) ON DELETE SET NULL,
  reason        TEXT NOT NULL,          -- extract_failed / conflict / low_confidence / quote_mismatch / geocode_failed
  draft         JSONB,                  -- 抽取草稿（ActivityDraft dump，含 evidence_quote）
  conflict_with BIGINT REFERENCES activities(id) ON DELETE SET NULL,  -- 冲突的主记录
  status        TEXT DEFAULT 'pending', -- pending / approved / rejected / merged
  reviewer      TEXT,
  resolved_at   TIMESTAMPTZ,
  created_at    TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX ON activity_review_queue (status, created_at);
```

> 除该审核队列外，本模块**不新增任何字段**；`source_registry`/`raw_pages`/`activities`/`venues` 的既有字段完全够用（调度用 `last_fetched_at + fetch_interval`、条件请求用 `raw_pages.etag/content_hash`、二级去重复用 `activities.embedding`）。若后续需要在 `source_registry` 记 `crawl_delay`/`contact_email`，同样走"回改 DD-01"流程，不在本模块私自扩展。

### 4.2 依赖上游（本模块调用，均不裸调外部）

| 能力 | 提供方 | 调用形态 | 说明 |
|---|---|---|---|
| 找官方入口 | `gpt-researcher`（pip 包）+ DD-04 `search` Provider | `ResearchAgent` / `provider.call(Req(op="web_search"))` | **仅取 URL**，报告不作事实 |
| LLM 结构化抽取 | DD-04 §6.4 `extract_fact` / PydanticAI Agent | `Agent(get_llm("activity_extract"), tools=[emit_activity])` | 输出带 `evidence_quote` |

## 5. 核心流程（逐阶段 + 可运行级代码）

> 代码基于 Python 3.11+ / Celery 5 / httpx / Playwright / PydanticAI / SQLAlchemy(异步) / pgvector。为聚焦流水线逻辑，DB 会话与 Provider 注入用依赖获取函数表示（`get_session()` / `get_provider()` / `get_retrieval_svc()`）。

### 5.0 编排骨架（单源全流程）

```python
# dd06/pipeline.py
import structlog
from dd06.fetch import fetch_page, FetchResult
from dd06.clean import clean_to_markdown
from dd06.extract import extract_activities          # PydanticAI + emit_activity
from dd06.normalize import normalize_activity
from dd06.dedup import find_duplicate, merge_evidence
from dd06.grade import grade_activity                # 接 DD-03 enforce_provenance
from dd06.store import upsert_activity, save_raw_page, enqueue_review
from dd06.registry import load_source, touch_source

log = structlog.get_logger()

@celery_app.task(name="dd06.crawl_source", bind=True, max_retries=3,
                 default_retry_delay=300)
def crawl_source(self, source_id: int) -> dict:
    src = load_source(source_id)                      # source_registry 行
    if not src.enabled:
        return {"skipped": "disabled"}

    # 1) 抓取（robots/限速/ETag 全在 fetch_page 内）
    fr: FetchResult = run_async(fetch_page(src))
    if fr.status == "not_modified":                   # 304：正文未变，跳过重抽
        touch_source(source_id)
        return {"skipped": "not_modified"}
    if not fr.ok:
        touch_source(source_id)
        raise self.retry(exc=RuntimeError(f"fetch_failed:{fr.http_status}"))

    # 2) 清洗（Readability/Jina → Markdown）
    clean_md = clean_to_markdown(fr.html, base_url=fr.url)

    # 3) 落原始页（去重：content_hash 无变化不重抽）
    raw_page_id, changed = save_raw_page(
        source_id=source_id, url=fr.url, http_status=fr.http_status,
        etag=fr.etag, clean_md=clean_md)
    touch_source(source_id)
    if not changed:
        return {"skipped": "content_unchanged"}

    # 4) LLM 抽取（PydanticAI + emit_activity，每字段带 evidence_quote）
    drafts = run_async(extract_activities(clean_md, city_code=src.city_code,
                                          source_url=fr.url))
    upserted, queued = 0, 0
    for d in drafts:
        # 4.1) evidence_quote 回锚校验（防幻觉硬闸）
        if not d.quotes_grounded_in(clean_md):
            enqueue_review(raw_page_id, source_id, reason="quote_mismatch",
                           draft=d.model_dump()); queued += 1; continue

        # 5) 归一（时间/城市/场馆/坐标 via 高德地理编码）
        try:
            norm = run_async(normalize_activity(d, src))
        except NormalizeError as e:
            enqueue_review(raw_page_id, source_id, reason="geocode_failed",
                           draft=d.model_dump()); queued += 1; continue

        # 6) 去重 & 实体对齐（fingerprint 一级 + pgvector 二级）
        dup = run_async(find_duplicate(norm))
        # 7) 定级（DD-03 enforce_provenance + validate_fact）
        graded = grade_activity(norm, src, fr)

        if dup and dup.trust_level <= src.trust_level:
            # 已有更高/同等可信主记录 → 合并证据，不覆盖主字段
            merge_evidence(dup.id, graded, conflict=norm.conflicts_with(dup))
        else:
            # 8) embed 入库（新记录或本源更可信 → upsert）
            emb = run_async(get_retrieval_svc().embed([norm.embed_text()]))
            upsert_activity(norm, graded, embedding=emb[0],
                            embedding_version=EMBEDDING_VERSION,
                            supersede=dup.id if dup else None)
        upserted += 1
    log.info("crawl_source.done", source_id=source_id,
             upserted=upserted, queued=queued)
    return {"upserted": upserted, "queued_for_review": queued}
```

### 5.1 来源注册表与调度器（Celery beat）

```python
# dd06/schedule.py
from celery.schedules import crontab

celery_app.conf.beat_schedule = {
    "dd06-dispatch-due-sources": {                # 每小时扫描到期源
        "task": "dd06.dispatch_due_sources",
        "schedule": crontab(minute=0),
    },
    "dd06-expire-activities": {                   # 每日 03:00 过期清理
        "task": "dd06.expire_activities",
        "schedule": crontab(minute=0, hour=3),
    },
}

@celery_app.task(name="dd06.dispatch_due_sources")
def dispatch_due_sources() -> dict:
    """低频克制：仅调度 enabled 且已过 fetch_interval 的源。"""
    due = fetch_due_source_ids()   # SQL 见下
    for sid in due:
        crawl_source.delay(sid)
    return {"dispatched": len(due)}
```

```sql
-- fetch_due_source_ids()：到期源（尊重 fetch_interval，低频）
SELECT id FROM source_registry
WHERE enabled = TRUE
  AND robots_ok = TRUE
  AND (last_fetched_at IS NULL
       OR last_fetched_at + fetch_interval < now())
ORDER BY last_fetched_at NULLS FIRST
LIMIT 200;                          -- 单轮上限，配合限速平滑
```

来源注册示例（种子/审核台写入；`trust_level` 对齐 PRD 七级）：

```python
# PRD 05 来源可信度 → source_type / trust_level 映射（本模块统一口径）
TRUST = {
    "official_venue": 1,   # 主办方/场馆/博物馆/剧院/体育馆官网
    "culture_bureau": 2,   # 文旅局 / 公共文化日历
    "open_dataset":   3,   # 开放活动数据接口
    "search":         4,   # 搜索发现（仅找入口）
```

### 5.2 抓取 Fetcher（httpx / Playwright + robots + ETag + 双层限速 + 真实 UA）

```python
# dd06/fetch.py
import httpx, hashlib
from urllib import robotparser
from dataclasses import dataclass
from dd06.ratelimit import token_bucket_acquire   # 复用 DD-04 Redis 令牌桶(rl:{key})
from dd06.cache import get_etag, robots_allowed_cached

UA = "WhereToGoBot/0.1 (+https://wheretogo.example/bot; contact: bot@wheretogo.example)"
GLOBAL_QPS, PER_DOMAIN_QPS = 5, 1        # 双层限速：全局 5 QPS、单域名 1 QPS

@dataclass
class FetchResult:
    ok: bool; url: str; http_status: int
    html: str | None; etag: str | None
    status: str                          # "ok" / "not_modified" / "blocked" / "error"

async def fetch_page(src) -> FetchResult:
    domain = httpx.URL(src.entry_url).host

    # (1) robots 强制校验：无明确许可默认不抓
    if not await robots_allowed_cached(src.entry_url, UA):
        mark_source_robots(src.id, ok=False)
        return FetchResult(False, src.entry_url, 0, None, None, "blocked")

    # (2) 双层令牌桶限速（全局 + 单域名），阻塞直到取得令牌或超时
    await token_bucket_acquire(f"rl:crawl:global", qps=GLOBAL_QPS)
    await token_bucket_acquire(f"rl:crawl:{domain}", qps=PER_DOMAIN_QPS)

    # (3) 条件请求：带上次 ETag，命中 304 直接短路（省抓省抽）
    headers = {"User-Agent": UA}
    if etag := await get_etag(src.entry_url):
        headers["If-None-Match"] = etag

    if src.parser_kind == "js":
        return await _fetch_playwright(src, headers)     # JS 重渲染页
    return await _fetch_httpx(src, headers)              # 静态页 / rss / api

async def _fetch_httpx(src, headers) -> FetchResult:
    async with httpx.AsyncClient(timeout=20, follow_redirects=True,
                                 headers=headers) as c:
        r = await c.get(src.entry_url)
        if r.status_code == 304:
            return FetchResult(True, str(r.url), 304, None, headers.get("If-None-Match"),
                               "not_modified")
        if r.status_code >= 400:
            return FetchResult(False, str(r.url), r.status_code, None, None, "error")
        return FetchResult(True, str(r.url), r.status_code, r.text,
                           r.headers.get("ETag"), "ok")

async def _fetch_playwright(src, headers) -> FetchResult:
    from playwright.async_api import async_playwright
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page(user_agent=UA)
        try:
            resp = await page.goto(src.entry_url, wait_until="networkidle", timeout=30000)
            html = await page.content()
            return FetchResult(True, src.entry_url, resp.status if resp else 200,
                               html, resp.headers.get("etag") if resp else None, "ok")
        finally:
            await browser.close()
```

```python
# dd06/cache.py —— robots 结果缓存（避免每次抓 robots.txt）
async def robots_allowed_cached(url: str, ua: str) -> bool:
    domain = httpx.URL(url).host
    cached = await redis.get(f"robots:{domain}")
    if cached is not None:
        rp = robotparser.RobotFileParser(); rp.parse(cached.decode().splitlines())
    else:
        async with httpx.AsyncClient(timeout=10, headers={"User-Agent": ua}) as c:
            try:
                txt = (await c.get(f"https://{domain}/robots.txt")).text
            except Exception:
                txt = ""                       # 取不到 robots：保守起见默认不抓
        if not txt:
            return False
        await redis.set(f"robots:{domain}", txt, ex=86400)   # 缓存 1 天
        rp = robotparser.RobotFileParser(); rp.parse(txt.splitlines())
    return rp.can_fetch(ua, url)
```

### 5.4 LLM 抽取（PydanticAI + `emit_activity` 工具，带 `evidence_quote`）

```python
# dd06/extract.py
from datetime import datetime
from pydantic import BaseModel, Field
from pydantic_ai import Agent, RunContext
from dd06.llm import get_llm                       # DD-04 §6.1 分层路由

class FieldQuote(BaseModel):
    """每个对外事实字段的原文引用，用于回锚校验（防幻觉）。"""
    value: str | None = None
    evidence_quote: str | None = Field(
        None, description="支撑该字段的原文片段，必须逐字来自正文")

class ActivityDraft(BaseModel):
    title: str
    venue: str | None = None
    start_text: FieldQuote                          # 原文时间描述（归一前）
    end_text:   FieldQuote | None = None
    price:      FieldQuote                           # 原文价格描述，不做换算
    booking:    FieldQuote | None = None             # 报名/购票入口
    category: str | None = None                      # 展览/演出/赛事/市集...
    city_code: str | None = None
    source_url: str | None = None

    def quotes_grounded_in(self, clean_md: str) -> bool:
        """回锚校验：所有非空 evidence_quote 必须逐字出现在清洗正文里。"""
        norm = "".join(clean_md.split())
        for fq in (self.start_text, self.end_text, self.price, self.booking):
            if fq and fq.evidence_quote:
                if "".join(fq.evidence_quote.split()) not in norm:
                    return False
        return True

    def embed_text(self) -> str:                    # DD-05 §4 待嵌文本构造
        return " ".join(filter(None, [self.title, self.venue or "",
                                       self.category or "", self.price.value or ""]))

# —— emit_activity 工具：LLM 每识别到一条活动就调用一次，产出结构化草稿 ——
_collected: dict = {}                               # run 级收集器（借 deps 注入）

extractor = Agent(
    get_llm("activity_extract"),                    # qwen-turbo，小模型高频抽取
    deps_type=list,
    system_prompt=(
        "你是活动信息抽取器。只从给定正文抽取【当周活动】，逐条调用 emit_activity。"
        "严格规则：①每个时间/价格/购票字段必须附 evidence_quote，逐字来自正文；"
        "②正文没有的信息一律留空，禁止臆造或推断价格/余票/营业时间；"
        "③一条活动调用一次 emit_activity。"),
)

@extractor.tool
def emit_activity(ctx: RunContext[list], draft: ActivityDraft) -> str:
    """LLM 调用此工具提交一条抽取到的活动草稿。"""
    ctx.deps.append(draft)
    return "ok"

async def extract_activities(clean_md: str, city_code: str,
                             source_url: str) -> list[ActivityDraft]:
    collected: list[ActivityDraft] = []
    await extractor.run(
        f"城市代码={city_code}\n来源URL={source_url}\n\n正文:\n{clean_md[:12000]}",
        deps=collected)
    for d in collected:                             # 补默认字段
        d.city_code = d.city_code or city_code
        d.source_url = d.source_url or source_url

```

> **为什么 `emit_activity` 工具 + `evidence_quote`**：工具调用天然结构化、可多条产出；`evidence_quote` 让每个强时效字段都能回锚原文，`quotes_grounded_in()` 在入库前做**逐字校验**——这是 DD-03「LLM 不许编造交通/票价/余票/营业时间」在情报侧的第一道工程护栏（LLM 来源字段还会被 DD-03 闸一进一步降级）。

### 5.5 归一（时间 / 城市 / 场馆 / 坐标 via 高德地理编码）

```python
# dd06/normalize.py
import dateparser
from dataclasses import dataclass, field
from dd06.provider import get_provider, Req         # DD-04 高德 Provider

class NormalizeError(Exception): ...

@dataclass
class NormActivity:
    title: str; city_code: str
    venue: str | None; category: str | None
    start_at: "datetime | None"; end_at: "datetime | None"
    price_text: str | None; booking_url: str | None
    location: tuple[float, float] | None            # (lng, lat) WGS84
    venue_id: int | None
    source_url: str; source_type: str
    draft: "ActivityDraft" = field(repr=False, default=None)
    fingerprint: str | None = None

    def embed_text(self) -> str:
        return " ".join(filter(None, [self.title, self.venue or "",
                                       self.category or "", self.price_text or ""]))
    def conflicts_with(self, other) -> bool:
        return (self.start_at != other.start_at) or (self.price_text != other.price_text)

async def normalize_activity(d: "ActivityDraft", src) -> NormActivity:
    # (1) 时间归一：中文口语 → TIMESTAMPTZ（Asia/Shanghai 落 UTC）
    start_at = dateparser.parse(
        d.start_text.value or "", languages=["zh"],
        settings={"TIMEZONE": "Asia/Shanghai", "RETURN_AS_TIMEZONE_AWARE": True})
    end_at = dateparser.parse(
        (d.end_text.value if d.end_text else "") or "", languages=["zh"],
        settings={"TIMEZONE": "Asia/Shanghai", "RETURN_AS_TIMEZONE_AWARE": True})
    if start_at is None:
        raise NormalizeError("start_at unparsable")

    # (2) 场馆/坐标：高德地理编码（经 DD-04 Provider，禁止裸调）
    location, venue_id = None, None
    if d.venue:
        prov = get_provider("amap")
        res = await prov.call(Req(op="geocode",
                                  params={"address": d.venue, "city": src.city_code},
                                  cache_ttl=30*86400))     # 地理编码缓存 30 天
        if res.ok and res.data.get("location"):
            lng, lat = map(float, res.data["location"].split(","))
            location = (lng, lat)
            venue_id = upsert_venue(src.city_code, d.venue, location, src.entry_url)

    norm = NormActivity(
        title=d.title.strip(), city_code=src.city_code, venue=d.venue,
        category=d.category, start_at=start_at, end_at=end_at,
        price_text=(d.price.value or None), booking_url=(d.booking.value if d.booking else None),
        location=location, venue_id=venue_id,
        source_url=d.source_url, source_type=src.source_type, draft=d)
    norm.fingerprint = make_fingerprint(norm)        # §5.6
    return norm
```

### 5.6 去重 & 实体对齐（`fingerprint` 一级 + pgvector 二级）

```python
# dd06/dedup.py
import hashlib, re
from dd06.provider import get_provider
from dd06.store import get_session

DEDUP_COS_THRESHOLD = 0.12        # cosine distance 阈值(<=)：<0.12 视为同一活动

def _norm_title(t: str) -> str:
    return re.sub(r"\s+", "", re.sub(r"[【】\[\]（）()·—\-—:：]", "", t)).lower()

def make_fingerprint(n) -> str:
    """一级去重键：hash(标准化标题 + 城市 + 场馆 + 开始日期)。"""
    day = n.start_at.astimezone().date().isoformat() if n.start_at else ""
    basis = f"{_norm_title(n.title)}|{n.city_code}|{_norm_title(n.venue or '')}|{day}"
    return hashlib.sha1(basis.encode()).hexdigest()

async def find_duplicate(n) -> "DupRef | None":
    session = get_session()
    # (1) 一级：fingerprint 精确命中（UNIQUE）
    row = await session.execute(
        "SELECT id, evidence->>'source_type' AS st FROM activities "
        "WHERE fingerprint = :fp", {"fp": n.fingerprint})
    if r := row.first():
        return DupRef(id=r.id, trust_level=TRUST.get(r.st, 9), matched="fingerprint")

    # (2) 二级：pgvector 语义近邻（同城同周同标题不同写法的多来源）
    emb = (await get_retrieval_svc().embed([n.embed_text()]))[0]
    row = await session.execute("""
        SELECT id, evidence->>'source_type' AS st,
               embedding <=> :vec AS dist
        FROM activities
        WHERE city_code = :city
          AND start_at::date = :day
          AND expires_at > now()
        ORDER BY embedding <=> :vec
        LIMIT 1
    """, {"vec": emb, "city": n.city_code,
          "day": n.start_at.date() if n.start_at else None})
    r = row.first()
    if r and r.dist is not None and r.dist <= DEDUP_COS_THRESHOLD:
        return DupRef(id=r.id, trust_level=TRUST.get(r.st, 9),
                      matched="semantic", dist=r.dist)
    return None
```

> **合并策略**（v1 §8.4）：命中重复且**已有主记录可信度 ≥ 本源** → 只 `merge_evidence`（把本源作为佐证证据追加/记录冲突，不覆盖主字段）；若**本源更可信**（如搜索源被官方源替换）→ upsert 覆盖主字段，`supersede` 旧记录。多来源冲突（时间/价格不一致）写入 `activity_review_queue(reason="conflict")` 待人工核。

```python
from dd03.types import Evidence, VerificationStatus, SourceType

def grade_activity(n, src, fr) -> dict:
    """对活动的对外事实字段逐一定级，产出落库用 evidence JSONB。"""
    st = src.source_type                       # official_venue / culture_bureau / ...
    url, fetched = n.source_url, fr_fetched_at(fr)

    # 逐字段过 DD-03 闸一（白名单）+ 闸二（缺出处降级）

        "activity.price_text":  enforce_provenance("activity.price_text", n.price_text, st, url, fetched),

    }
    facts = {k: validate_fact(v) for k, v in facts.items()}

    # 活动整体 verification_status 取字段中"最保守"的一档（决定检索可见性）
    overall = min((f.evidence.verification_status for f in facts.values()),
                  key=_status_rank)
    ev: Evidence = facts["activity.start_at"].evidence
    ev.verification_status = overall
    return {"evidence": ev.model_dump(mode="json"),
            "verification_status": overall.value,
            "field_facts": {k: v.model_dump(mode="json") for k, v in facts.items()}}

# 六态保守序：expired/unknown/estimated < public_source_observed < official < confirmed
_ORDER = ["expired", "unknown", "estimated",
          "public_source_observed", "official_source_confirmed", "confirmed_by_user"]
def _status_rank(s) -> int:
    return _ORDER.index(s.value if hasattr(s, "value") else s)
```

> **定级要点**：`search` 来源即使抓到页面，`enforce_provenance` 依 DD-03 §5 白名单——`activity.*` 白名单**不含 `search`**——会被降级为 `estimated`；只有回到官方入口（`official_venue`/`culture_bureau`/`open_dataset`/`user_provided`）抓取，才可能得到 `official_source_confirmed`/`public_source_observed`。这正是 v1.1 E④「gpt-researcher 只找入口、事实回官方」的落地：**补搜发现的 URL 若是官方站，则以 `official_venue` 注册新源再抓，才拿确认级**。

| **DD-02** | `research` 节点 → `research_weekend_activities.delay()` | 被触发 | 检索空/不足时异步补搜；**不阻塞规划流**；DD-02 对 `activities` 只读 |
| **DD-08** | 经 DD-05 检索间接消费 `activities` | 只读 | 城市打分/活动亮点透传 evidence，不改证据 |
| **运营/审核台** | `source_registry` 维护、`activity_review_queue` 处理 | 读写 | 唯一人工写 `activities` 通道，仍经 `upsert_activity` 定级 |

## 7. 证据与状态处理（引用 DD-03 §5 定级表）

本模块**不定义**定级规则，只**调用** DD-03 并保证接线一致。落级完全由 `(field, source_type)` 经 `enforce_provenance` 决定：

| 命中来源（source_type） | trust_level | 活动字段落级（经 DD-03） | 能否作核心活动 | 检索可见性（DD-05 硬过滤） |
|---|---|---|---|---|
| `official_venue`（场馆/主办方官网） | 1 | `official_source_confirmed` | ✅ | 可见 |
| `culture_bureau`（文旅局/公共文化日历） | 2 | `official_source_confirmed` | ✅ | 可见 |
| `open_dataset`（开放活动数据接口） | 3 | `public_source_observed`（标"待确认"） | ⚠️ 可，标注待确认 | 可见 |
| `search`（搜索发现，未回官方核实） | 4 | `unknown`（白名单不含 search → 降级） | ❌ 不作唯一核心活动 | **不可见**（被 DD-05 过滤） |
| `user_provided`（用户提供链接） | 5 | `confirmed_by_user`（用户回填确认场景） | ✅ | 可见 |
| `editorial`（人工精选） | 6 | 需审核台以官方/用户语义落级，否则 `estimated` | 审核后可 | 依落级 |
| `community`（内容社区） | 7 | 仅灵感，**绝不作唯一证据** | ❌ | **不可见** |
| 已过 `expires_at` | — | `expired` | ❌ 自动下架 | 不可见 |

**关键规则（对齐 DD-03 §5 白名单 `activity.*` = `{official_venue, culture_bureau, open_dataset, user_provided}`）**：

1. **搜索发现只找入口**：`search` 不在 `activity.*` 白名单，`enforce_provenance` 直接降 `estimated`；若 `source_url` 缺失再经闸二降 `unknown`。要拿确认级，必须把发现的官方 URL **注册为 `official_venue` 源重抓**（§5.10）。
2. **缺出处降级**：即便标 `official_source_confirmed`，若 `source_url`/`fetched_at` 缺失，`validate_fact`（闸二）降为 `unknown`——本模块入库时 `source_url=raw_pages.url`、`fetched_at=raw_pages.fetched_at` 必填，规避此路。
3. **活动整体态取最保守**：`start_at`/`price_text`/`booking_url` 三字段分别定级，活动 `verification_status` 取最保守一档（§5.7 `_status_rank`），保证检索层"官方核心活动"名副其实。
4. **不经闸三**：活动字段不属 `train.*`/`flight.*`/`*.availability`，不触发 DD-03 闸三；但 `availability_status` 恒为 `user_must_confirm`（余票禁编，PRD 硬约束），余票核实交用户。
5. **不自造 confirmed**：本模块任何路径都经 `enforce_provenance` 产 `Evidence`，绝不手工构造 `confirmed_*`（DD-03 §8 接线铁律，lint 静态扫描保证无绕过）。

## 8. 降级与异常（对齐 v1 §10 韧性表）

| 场景 | 触发点 | 降级行为 | 落级/标注 |
|---|---|---|---|
| **抓取失败/超时** | `fetch_page` 非 2xx/异常 | Celery `self.retry`（指数退避 ≤3 次）；仍失败→入 `activity_review_queue(extract_failed)`，展示**链接请用户确认** | 该源本轮无新活动，不影响已有库 |
| **robots 不允许** | `robots_allowed_cached=False` | 标 `source_registry.robots_ok=False`、视策略停用，**不抓** | — |
| **页面结构变化/抽取空** | `extract_activities` 返回空或字段全空 | 降级为"展示官方链接，请用户确认时间/价格"；异常入审核台 | v1 §10「官方页面结构变化」行 |
| **evidence_quote 回锚失败** | `quotes_grounded_in=False` | 丢弃该草稿 + 入审核台 `quote_mismatch`（疑似幻觉） | 不入库，防幻觉 |
| **地理编码失败** | 高德 `geocode` 降级/`unknown`（DD-04 五件套） | 活动仍入库但 `location=NULL`、`venue_id=NULL`；入审核台 `geocode_failed` 待补 | 不影响非地理检索 |
| **搜索服务不可用** | `gpt-researcher`/DD-04 search 熔断 | 补搜返回**关键词 + 已注册官方源清单**，DD-02 research 用其降级出稿 | v1 §10「搜索服务不可用」行 |
| **embedding 服务不可用** | `svc.embed` 抛错 | 入库暂缓该批（重试队列）；或先入库 `embedding=NULL` 后台补嵌（DD-05 降级为纯 BM25 仍可召回） | `embedding_version` 标待补 |
| **LLM 抽取不可用** | `extractor.run` 异常 | 该源本轮跳过、下轮重试；已有活动库不受影响（读写解耦，规划流照常读旧库） | — |
| **来源冲突** | `find_duplicate` 命中但时间/价格不一致 | 保留高可信主记录，冲突入审核台 `conflict`；官方源覆盖搜索源 | v1 §8.4 |

**总原则**（v1 §10）：任何单点失效，**已入库的活动库照常供规划流只读**（读写解耦的最大红利），最差补搜结果 = "unknown + 官方入口清单"，绝不空结果、绝不编造。

## 9. 合规红线（写进代码，不靠自觉 · v1 §8.3 / §12）

1. **只抓官方公开页**：`source_registry` 只注册官方场馆/文旅日历/开放数据/官方购票入口；不抓登录后内容、不碰交易平台余票/实时价、不碰个人数据。
2. **robots 强制校验**：每次抓取前 `robots_allowed_cached()`；**取不到 robots.txt 默认不抓**（保守）；不允许的路径直接 `blocked`。robots 结果缓存 1 天。
3. **双层限速**：全局令牌桶 `rl:crawl:global`（5 QPS）+ 单域名 `rl:crawl:{domain}`（1 QPS），复用 DD-04 Redis 令牌桶；夜间调度为主，`fetch_interval` 默认 1 天低频。
4. **真实 UA + 联系邮箱**：`WhereToGoBot/0.1 (+主页; contact: bot@...)`，可被站方识别与联系。
5. **尊重缓存头**：`If-None-Match`(ETag) 条件请求；304 直接短路不重抓；`content_hash` 无变化不重抽（省抓省抽省 token）。
6. **内容社区仅灵感**：`community`(trust 7) **绝不作为唯一证据源**（定级降级 + 检索硬过滤双重保证）。
7. **不建交易抓取依赖**：架构层面不抓 12306/航司/OTA 的票务数据（PRD 原则：不碰交易）。
8. **gpt-researcher 只找入口**：其报告不入库为事实，只取 `source_urls`（§5.10 红线）。

> 合规不是配置项而是**代码路径**：robots 校验、限速、UA、ETag、来源白名单全在 `fetch.py`/`registry.py` 内联执行，绕过即抓不动。

```python
#  · 相同输入 LLM 结果缓存 24h（DD-04 §4.1）
```

| 配额项 | 键（DD-01 §9.1） | 上限策略 |
|---|---|---|
| 抓取全局/单域 QPS | `rl:crawl:global` / `rl:crawl:{domain}` | 5 / 1，令牌桶 |
| 高德 geocode | `quota:amap:{yyyymmdd}` | DD-04 日上限，接近降级（无坐标入库） |
| 搜索 API | `quota:search:{yyyymmdd}` | 仅补搜低频调用 |
| 抽取 LLM | `quota:llm:{yyyymmdd}` | content_hash/ETag/缓存三重省；小模型 |

**成本控制排序**（v1 §11）：① ETag 304 + content_hash 免重抓/重抽（最大项）→ ② 小模型 + 正文截断 + LLM 结果缓存 → ③ geocode 30 天缓存 → ④ 低频调度。
