# DD-03 证据体系与防幻觉护栏 · 详细设计

**详细设计系列 · 横切契约文档 · v1.0 · 2026 年 7 月**

> 本文定义全系统的**可信度机制**：`Fact/Evidence` 类型、六态语义、字段级来源白名单、**Provenance Guard 三闸**、前端渲染契约、CI 断言。它是产品硬 KPI —— **"未确认字段被错误展示为已确认的次数 = 0"** —— 的工程落地。
>
> **上游依据**：v1 §6.1（六态）、§7.3（Guard 三闸）、v1.1 增补 B（证据可视 P0）、DD-01（evidence JSONB 规范）、DD-02（compose 出稿闸）。
> **下游消费者**：所有"产出对外事实"的模块（DD-05/06/08/09/10/11）+ DD-13（渲染）+ 前端。
> **一句话**：**能确定性/官方/用户确认的才算"事实"；LLM 与搜索产出一律降级为 `estimated`/`unknown`；交通票价余票禁止生成。**

## 1. 模块职责与边界

| 项 | 说明 |
|---|---|
| **职责** | 提供 `Fact/Evidence` 类型与校验、六态定级规则、Provenance Guard 三道闸、前端渲染契约、CI 断言。 |
| **边界内** | 类型定义、`FIELD_SOURCE_POLICY`、`enforce_provenance`/`map_status`、出稿断言、渲染映射表、埋点。 |
| **边界外** | 各字段"值"从哪来（在对应领域模块）；本文只管"值旁边的证据怎么定级、能不能展示为已确认"。 |
| **架构位置** | v1 §4.1"AI 能力层 · Provenance Guard 校验"，横切所有产事实节点。 |

---

## 2. 设计目标与非目标

**目标**：① `estimated`/`unknown` 与 `confirmed` 在数据与 UI 上**永不混淆**；② 交通/票价/余票/营业时间等强时效字段**禁止 LLM 编造**；③ 护栏是**纯函数 + CI 断言**，不依赖框架，可单测。

**非目标**：❌ 不做"第二个大模型质检"（马蜂窝路线，推理成本翻倍）——我们用**确定性规则 + 来源白名单**质检，更便宜、可解释、CI 可断言（v1 洞察）。

## 3. `Fact / Evidence` 类型（权威，全系统统一）

```python
from enum import Enum
from datetime import datetime
from typing import Generic, TypeVar
from pydantic import BaseModel, HttpUrl

class VerificationStatus(str, Enum):
    confirmed_by_user         = "confirmed_by_user"
    official_source_confirmed = "official_source_confirmed"
    public_source_observed    = "public_source_observed"
    estimated                 = "estimated"
    unknown                   = "unknown"
    expired                   = "expired"

class SourceType(str, Enum):
    official_venue = "official_venue"; culture_bureau = "culture_bureau"
    open_dataset   = "open_dataset";   search         = "search"
    user_provided  = "user_provided";  editorial      = "editorial"
    community      = "community";       amap           = "amap"
    qweather       = "qweather";        variflight     = "variflight"
    llm            = "llm"

class Evidence(BaseModel):
    source_type: SourceType
    source_url: HttpUrl | None = None
    fetched_at: datetime | None = None
    verification_status: VerificationStatus
    confidence: float = 0.0            # 0~1
    note: str | None = None

T = TypeVar("T")
class Fact(BaseModel, Generic[T]):
    """任何对用户展示的事实值都用 Fact 包装：值 + 证据。"""
    value: T | None
    evidence: Evidence
```

> 落库形态见 DD-01 §5（`evidence` 作为标准 JSONB 内嵌在事实字段旁）。抽取子调用（DD-04 PydanticAI）**直接产出 `Fact`**，天然承载。

## 4. 六态语义与默认定级 `map_status`

| 状态 | 语义 | 能否作为"已确认"展示 | 典型来源 |
|---|---|---|---|
| `confirmed_by_user` | 用户回填并逐字段确认 | ✅ | 用户 |
| `official_source_confirmed` | 官方场馆/主办方/文旅日历核实 | ✅ | official_venue / culture_bureau |
| `public_source_observed` | 公开来源观察到，未回官方核实 | ⚠️ 需标注"待确认" | open_dataset / amap / qweather / variflight |
| `estimated` | 系统估算（缓冲时长、粗距） | ❌ 必须标"估算" | rule / llm |
| `unknown` | 系统不知道 | ❌ 明确"不知道" | 缺来源 |
| `expired` | 已过期 | ❌ 自动下架 | 过 `expires_at` |

```python
def map_status(source_type: str, verified_at_official: bool = False) -> VerificationStatus:
    if source_type == "user_provided":                       return VerificationStatus.confirmed_by_user
    if source_type in ("official_venue", "culture_bureau"):  return VerificationStatus.official_source_confirmed
    if source_type in ("open_dataset", "amap", "qweather", "variflight"):
        return VerificationStatus.public_source_observed
    if source_type == "search":
        return (VerificationStatus.public_source_observed if verified_at_official
                else VerificationStatus.unknown)             # 搜索仅找入口，未核实→unknown
    if source_type in ("rule", "llm"):                       return VerificationStatus.estimated
    return VerificationStatus.unknown
```

## 5. 字段级来源白名单 `FIELD_SOURCE_POLICY`（权威，闸一）

> **只有列出的来源能给对应字段"确认级"状态；其余（尤其 `llm`/`search`）一律降级。** LLM **不在任何交通/票价/余票字段的白名单里**。

```python
FIELD_SOURCE_POLICY: dict[str, set[str]] = {
    # —— 交通：只能来自用户回填或官方/付费航班数据 ——
    "train.train_no":        {"user_provided", "official_venue"},
    "train.departure_time":  {"user_provided", "official_venue"},
    "train.price":           {"user_provided", "official_venue"},          # 票价禁编
    "train.availability":    {"user_provided", "official_venue"},          # 余票禁编
    "flight.flight_no":      {"user_provided", "official_venue", "variflight"},
    "flight.dep_time":       {"user_provided", "official_venue", "variflight"},
    "flight.price":          {"user_provided", "official_venue"},          # 实时价回官方
    # —— 活动：官方/开放数据/用户 ——
    "activity.start_at":     {"official_venue", "culture_bureau", "open_dataset", "user_provided"},
    "activity.price_text":   {"official_venue", "culture_bureau", "open_dataset", "user_provided"},
    "activity.booking_url":  {"official_venue", "culture_bureau", "open_dataset", "user_provided"},
    # —— 餐饮/POI/路线：地图/官方/用户/规则 ——
    "restaurant.open_hours": {"amap", "official_venue", "user_provided"},
    "restaurant.phone":      {"amap", "official_venue", "user_provided"},
    "route.minutes":         {"amap", "rule", "user_provided"},
    "route.distance_m":      {"amap", "rule", "user_provided"},
    # —— 天气：仅气象源 ——
    "weather.precip_prob":   {"qweather"},
    "weather.alert":         {"qweather"},
}
```

## 6. Provenance Guard 三闸（核心）

```python
class ProvenanceError(Exception): ...

# —— 闸一：字段级来源白名单 —— 违规不拒绝值，但强制降级状态
def enforce_provenance(field: str, value, source_type: str,
                       source_url=None, fetched_at=None) -> Fact:
    allowed = FIELD_SOURCE_POLICY.get(field, set())
    if source_type in allowed:
        status = map_status(source_type, verified_at_official=(source_url is not None))
    else:
        status = VerificationStatus.estimated          # 来源不足以确认 → 降级
    ev = Evidence(source_type=source_type, source_url=source_url,
                  fetched_at=fetched_at, verification_status=status,
                  note=None if source_type in allowed else "来源不足以确认，需用户/官方核实")
    return Fact(value=value, evidence=ev)

# —— 闸二：结构化输出 + schema 校验 —— 缺来源的"事实"判 unknown
def validate_fact(fact: Fact) -> Fact:
    ev = fact.evidence
    needs_source = ev.verification_status in (
        VerificationStatus.official_source_confirmed, VerificationStatus.public_source_observed)
    if needs_source and not (ev.source_url and ev.fetched_at):
        ev.verification_status = VerificationStatus.unknown       # 无出处不得称"观察到/官方"
        ev.note = "缺 source_url/fetched_at，降级为 unknown"
    return fact

# —— 闸三：交通/票价/余票"禁止生成" —— compose 出稿前断言（进 CI 单测）
FORBIDDEN_LLM_FIELDS = ("train.", "flight.")   # 前缀匹配
def assert_no_fabricated_transport(bundle: dict) -> None:
    for field, fact in iter_facts(bundle):
        is_transport = field.startswith(FORBIDDEN_LLM_FIELDS) or field.endswith(".availability")
        if is_transport and fact.evidence.source_type == "llm":
            raise ProvenanceError(f"字段 {field} 由 LLM 生成，违反禁编规则")
```

**闸三的产品语义**：任何 `train.*` / `flight.*` / `*.availability` 若来源是 `llm`，在 `compose`（DD-02）出稿前**直接抛错**，由组装器替换为"**待你在官方平台确认**"占位。**这条断言进 CI 单测**，对应硬 KPI。

## 7. 前端渲染契约（v1.1 增补 B 的 P0 必做项）

**证据可视是可信度，不是美化，必做。** 前端组件**直接读 `evidence.verification_status`** 决定样式，禁止把估算当已确认：

| verification_status | 视觉规范（够用即可，不追酷炫） | 文案 |
|---|---|---|
| `confirmed_by_user` | 实心✓ 角标，正常底色 | "已确认" |
| `official_source_confirmed` | 官方✓ 角标 + 来源链接可点 | "官方来源" |
| `public_source_observed` | 虚线边/浅色角标 + "待确认" | "公开来源·待确认" |
| `estimated` | 斜体/灰底 + "~估算" | "估算值" |
| `unknown` | 明确占位"暂无" | "暂无/请补充" |
| `expired` | 删除线/隐藏 | "已过期" |

```tsx
// 前端唯一入口组件：所有事实字段都经它渲染，杜绝绕过
function FactField({ fact }: { fact: Fact }) {
  const s = fact.evidence.verification_status;
  return <span className={STATUS_STYLE[s]} title={fact.evidence.note ?? ""}>
    {fact.value ?? "暂无"} <StatusBadge status={s} url={fact.evidence.source_url} />
  </span>;
}
```

> 前端此阶段**只做**：证据六态可辨 + 结构化卡片静态渲染（v1.1 B）。滑杆/双栏地图/拖拽编辑延后。

## 8. 与各模块的接线（谁产事实、如何标注）

| 模块 | 产出的事实 | 必须调用 |
|---|---|---|
| DD-05 检索 | 活动/餐厅候选（带原 evidence 透传） | 透传 activities.evidence，不新造 |
| DD-06 情报流水线 | activities 的 start_at/price/url | `enforce_provenance` + `validate_fact`（官方源→confirmed） |
| DD-08 目的地发现 | 城市卡的理由/预算/耗时 | 门到门=rule/amap→observed/estimated；活动亮点透传 |
| DD-09 交通 | 门到门耗时、策略卡、起售时间 | 缓冲=rule→estimated；票价/余票**禁编**（闸三） |
| DD-10 回填 | 车次/航班/酒店 | 用户确认→`confirmed_by_user`；未确认不入时间线 |
| DD-11 餐饮/接驳 | 营业时间/电话/路线耗时 | amap→observed；rule→estimated |
| DD-13 组装 | 最终 bundle | **compose 前跑闸三断言**（最终闸） |

> **接线铁律**：任何模块产出对外事实，**不得直接构造 `Evidence` 的 `confirmed` 状态**，必须经 `enforce_provenance`（由 field 与 source_type 决定），保证定级一致、可审计。

## 9. 与 PydanticAI 的关系（DD-04）

- 抽取子调用（回填、活动字段）用 PydanticAI `output_type=Fact`（或结构含 `evidence_quote`），**输出即校验过的结构化事实**；
- 抽取结果先过 `validate_fact`（闸二），再按来源过 `enforce_provenance`（闸一）；
- LLM 产出的字段 `source_type='llm'`，天然被闸一降级、被闸三拦截（若是交通字段）。

---

## 10. 可观测与 KPI

- **硬 KPI 埋点**：`assert_no_fabricated_transport` 每次在 `compose` 执行；违规计数必须恒为 0，非 0 立即报警（DD-02 §12）。
- 统计：各字段的六态分布（官方源占比、estimated 占比、unknown 占比）——对应 PRD 可信度指标"核心活动官方来源比例、过期活动率"。
- 抽样审计：随机抽 bundle 人工核对"展示态 vs 真实来源"，回归防漂移。

---

## 11. 效果与验收标准（DoD）

1. **CI 断言**：构造"LLM 生成的车次/票价"输入，`assert_no_fabricated_transport` **必抛错**（红线用例）。
2. **降级正确**：`search` 未核实来源 → `unknown`；`llm` 活动时间 → `estimated`；官方页 → `official_source_confirmed`。
3. **缺出处降级**：`public_source_observed` 但无 `source_url/fetched_at` → `validate_fact` 降为 `unknown`。
4. **前端渲染**：六态样式快照测试，`estimated`/`unknown` 与 `confirmed` 视觉可辨（组件级测试）。
5. **接线覆盖**：DD-05/06/09/10/11 产事实处均经 `enforce_provenance`（静态扫描/lint 保证无绕过）。

## 13. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 开发绕过 `enforce_provenance` 直接构造 confirmed | lint 静态扫描 + code review + 接线铁律 |
| `FIELD_SOURCE_POLICY` 漏配新字段 | 默认 `set()`→自动降级 estimated（保守安全）；新字段评审补白名单 |
| 前端某处直接渲染 value 未走 FactField | 组件层统一入口 + 快照测试兜底 |
